Assistant

Below is a proof strategy that I think is by far the most promising. It uses high-degree totally real number fields. The guiding idea is:

  • Small sumset comes from putting the set inside an archimedean box: if all conjugates of all elements are bounded by a fixed constant, then the sumset also lies in a comparable box, whose number of algebraic integers is only exponential in the degree.
  • Small product set comes from saturating the set by many small units. Many elements of the set then generate the same principal ideal, so products have many forced multiplicative collisions.

I will develop the approach in detail. The combinatorial/geometry-of-numbers part can be made essentially complete. The one deep arithmetic input is the existence of an infinite tower of totally real fields with bounded root discriminant and regulator at most exponential in the degree; this is a standard consequence of totally real class field towers plus analytic class number bounds, but if one wants a fully self-contained proof, this is the main remaining arithmetic gap to fill.

1. The main arithmetic template

Let \(K/\mathbb Q\) be a totally real number field of degree \(d\), with real embeddings

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow \mathbb R. \]

Write \(\mathcal O_K\) for its ring of integers, \(\Delta_K\) for its discriminant, and \(R_K\) for its regulator.

For \(Z\ge 1\), define the archimedean box

\[ B_K(Z) := \left\{\alpha\in \mathcal O_K: |\sigma_j(\alpha)|\le Z \text{ for all } j=1,\dots,d \right\}. \]

For \(s\ge 0\), define the small-unit box

\[ U_K(s) := \left\{u\in \mathcal O_K^\times: |\log |\sigma_j(u)||\le s \text{ for all } j=1,\dots,d \right\}. \]

The eventual construction will be of the following form.

Choose fixed large constants \(L>T>0\), independent of \(K\). Set

\[ Y:=\frac{e^{L-T}}{4}, \qquad M:=\lceil 2Y\rceil. \]

Define a “core” set

\[ C_K := \left\{ M+\beta: \beta\in B_K(Y) \right\}. \]

Then every \(c\in C_K\) satisfies

\[ Y\le |\sigma_j(c)|\le 4Y \qquad\text{for every } j. \]

Now saturate \(C_K\) by the small units:

\[ \widetilde A_K := U_K(T)\,C_K = \{uc:u\in U_K(T),\,c\in C_K\} \subset \mathcal O_K. \]

Finally, choose one real embedding, say \(\sigma_1\), and set

\[ A_K:=\sigma_1(\widetilde A_K)\subset \mathbb R. \]

Because \(\sigma_1\) is injective on \(K\), cardinalities of sumsets and product sets are preserved:

\[ |A_K+A_K|=|\widetilde A_K+\widetilde A_K|, \qquad |A_KA_K|=|\widetilde A_K\widetilde A_K|. \]

So it suffices to work inside \(K\).

2. Why this construction should work

Let \(X:=e^L\). By construction,

\[ 4Ye^T=e^L=X. \]

Thus every \(a\in \widetilde A_K\) satisfies

\[ |\sigma_j(a)|\le X \qquad\text{for all }j. \]

Therefore

\[ \widetilde A_K+\widetilde A_K\subset B_K(2X). \]

So \(|A_K+A_K|\) is bounded above by the number of algebraic integers in a box of radius \(2X\). If \(K\) has bounded root discriminant and \(X\) is fixed, this is only exponential in \(d\).

For products, the crucial point is that \(\widetilde A_K\) is saturated by \(U_K(T)\). If \(a=uc\in \widetilde A_K\), then for every \(v\in U_K(T)\), the element \(vc\) also lies in \(\widetilde A_K\), and all these elements generate the same principal ideal. Therefore each principal ideal represented by \(\widetilde A_K\) has at least \(|U_K(T)|\) representatives in \(\widetilde A_K\).

Consequently, the number of principal ideals represented by \(\widetilde A_K\) is at most

\[ \frac{|\widetilde A_K|}{|U_K(T)|}. \]

Thus the number of principal ideals represented by products \(ab\), with \(a,b\in \widetilde A_K\), is at most

\[ \left(\frac{|\widetilde A_K|}{|U_K(T)|}\right)^2. \]

For a fixed principal ideal, the number of generators that can actually occur as products \(ab\) is controlled by a slightly larger unit box. This gives

\[ |\widetilde A_K\widetilde A_K| \lesssim |\widetilde A_K|^2 \cdot \frac{|U_K(O(T))|}{|U_K(T)|^2}. \]

A lattice-doubling estimate for the logarithmic unit lattice gives

\[ |U_K(O(T))|\le q^d |U_K(T)| \]

for an absolute \(q=q(L,T)\). Hence

\[ |\widetilde A_K\widetilde A_K| \le |\widetilde A_K|^2 \cdot \frac{q^d}{|U_K(T)|}. \]

If \(|U_K(T)|\ge e^{\eta d}\) for some \(\eta>\log q\), then this gives a fixed exponential saving in \(d\). Since \(|\widetilde A_K|\le e^{O(d)}\), this becomes a fixed power saving in \(|\widetilde A_K|\).

3. Arithmetic input needed

The construction needs an infinite sequence of totally real fields \(K_i\) of degrees \(d_i\to\infty\) satisfying two uniform bounds.

Arithmetic Input

There exist constants \(D,E>1\) and infinitely many totally real number fields \(K_i\) with \(d_i=[K_i:\mathbb Q]\to\infty\) such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

and

\[ R_{K_i}\le E^{d_i}. \]

This is the main deep arithmetic ingredient.

Why this input is plausible / standard

A standard source is a totally real narrow Hilbert class field tower. Martinet’s construction gives a totally real field with an infinite totally real class field tower. Along an unramified tower, the root discriminant remains constant, giving the first bound.

The regulator bound follows from the analytic class number formula plus a standard Landau/Stark upper bound for the residue of \(\zeta_K(s)\) at \(s=1\). Namely, for a totally real field,

\[ \operatorname*{Res}_{s=1}\zeta_K(s) = \frac{2^{d-1}h_KR_K}{\sqrt{|\Delta_K|}}, \]

so

\[ R_K \le h_KR_K = 2^{1-d}\sqrt{|\Delta_K|} \operatorname*{Res}_{s=1}\zeta_K(s). \]

If the root discriminant is bounded, standard residue bounds give

\[ \operatorname*{Res}_{s=1}\zeta_K(s)\le C(D)^d, \]

hence

\[ R_K\le E^d \]

for some \(E=E(D)\).

Thus, for this proof plan, the arithmetic input is not a conceptual obstruction; it is a known but deep number-theoretic package.

4. Geometry-of-numbers lemmas

I now prove the elementary counting estimates needed for the construction.

Lemma 1: Additive box upper and lower bounds

Let \(K\) be totally real of degree \(d\). For \(Z\ge 1\),

\[ B_K(Z) = \{\alpha\in\mathcal O_K:|\sigma_j(\alpha)|\le Z\ \forall j\}. \]

Then:

  1. Upper bound:
\[ |B_K(Z)|\le (2Z+1)^d. \]
  1. Lower bound:
\[ |B_K(Z)|\ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

Proof of the upper bound

If \(\alpha,\beta\in\mathcal O_K\) are distinct, then \(\gamma:=\alpha-\beta\) is a nonzero algebraic integer. Therefore

\[ |N_{K/\mathbb Q}(\gamma)| = \prod_{j=1}^d |\sigma_j(\gamma)| \]

is a positive integer, hence at least \(1\). Thus

\[ \max_j |\sigma_j(\gamma)|\ge 1. \]

So the embedded lattice \(\sigma(\mathcal O_K)\subset\mathbb R^d\) is \(1\)-separated in the sup norm.

The points of \(B_K(Z)\) lie in \([-Z,Z]^d\). Around each such point put an open sup-norm cube of side length \(1\). These cubes are disjoint and lie inside \([-Z-\tfrac12,Z+\tfrac12]^d\). Therefore

\[ |B_K(Z)|\le (2Z+1)^d. \]

Proof of the lower bound

The Minkowski embedding \(\sigma(\mathcal O_K)\subset \mathbb R^d\) is a lattice of covolume \(\sqrt{|\Delta_K|}\).

Let

\[ S=[-Z/2,Z/2]^d. \]

By Blichfeldt’s principle, some translate of \(S\) contains at least

\[ \frac{\operatorname{vol}(S)}{\sqrt{|\Delta_K|}} = \frac{Z^d}{\sqrt{|\Delta_K|}} \]

lattice points, up to an additive \(O(1)\) error. Taking differences from one fixed point in that translate gives distinct lattice points in

\[ S-S=[-Z,Z]^d. \]

Thus

\[ |B_K(Z)|\ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

This proves the lemma. \(\square\)

Lemma 2: Many small units from a regulator bound

Let

\[ U_K(s) = \left\{u\in\mathcal O_K^\times: |\log|\sigma_j(u)||\le s\ \forall j \right\}. \]

There is an absolute constant \(c_U>0\) such that

\[ |U_K(s)| \ge \frac{(c_Us)^{d-1}}{R_K}-1. \]

In particular, if \(R_K\le E^d\) and \(s\) is a sufficiently large fixed constant, then for all sufficiently large \(d\),

\[ |U_K(s)|\ge \left(\frac{c_Us}{E}\right)^d. \]

Proof

Consider the logarithmic embedding of the unit group:

\[ \lambda:\mathcal O_K^\times\to H_d, \qquad u\mapsto (\log|\sigma_1(u)|,\dots,\log|\sigma_d(u)|), \]

where

\[ H_d=\{x\in\mathbb R^d:x_1+\cdots+x_d=0\}. \]

Modulo the finite kernel \(\{\pm 1\}\), the image is a full lattice \(\Lambda_K\subset H_d\) of covolume \(R_K\).

Let

\[ Q_s:=H_d\cap[-s,s]^d. \]

The \((d-1)\)-dimensional volume of \(Q_s\) is at least \(c_0^{d}s^{d-1}\) for some absolute \(c_0>0\). Indeed, central sections of cubes have volume comparable to the coordinate hyperplane section; one may take a very small absolute \(c_0\) without optimizing.

Apply Blichfeldt’s principle in \(H_d\) to \(\frac12 Q_s\). Some translate contains at least

\[ \frac{\operatorname{vol}_{H_d}(\frac12Q_s)}{R_K} \]

points of \(\Lambda_K\). Taking differences from one of them gives distinct lattice points in \(Q_s\). Hence

\[ |\Lambda_K\cap Q_s| \ge \frac{\operatorname{vol}_{H_d}(\frac12Q_s)}{R_K}-1 \ge \frac{(c_Us)^{d-1}}{R_K}-1 \]

for an absolute \(c_U>0\).

Lifting back to units only changes constants by the kernel \(\{\pm1\}\). This proves the lemma. \(\square\)

Lemma 3: A unit-box dilation bound

Let \(s'\ge s>0\). Put

\[ m:=\frac{s'}{s}. \]

There is an integer

\[ q\le 2m+3 \]

such that

\[ |U_K(s')|\le q^d |U_K(s)|. \]

Proof

Work in the logarithmic unit lattice \(\Lambda_K\subset H_d\). Let

\[ Q_s=H_d\cap[-s,s]^d. \]

Choose an integer \(q>2m\). Partition \(\Lambda_K\cap Q_{s'}\) into residue classes modulo \(q\Lambda_K\). There are \(q^{d-1}\le q^d\) such classes.

If \(x,y\in \Lambda_K\cap Q_{s'}\) lie in the same class modulo \(q\Lambda_K\), then

\[ x-y=qz \]

for some \(z\in\Lambda_K\). Since \(x,y\in Q_{s'}=mQ_s\),

\[ z=\frac{x-y}{q}\in \frac{2m}{q}Q_s\subset Q_s. \]

Thus, inside each residue class, the number of points is at most \(|\Lambda_K\cap Q_s|\). Therefore

\[ |\Lambda_K\cap Q_{s'}| \le q^d|\Lambda_K\cap Q_s|. \]

Passing from logarithmic lattice points to units changes only the harmless \(\{\pm1\}\)-kernel, so

\[ |U_K(s')|\le q^d|U_K(s)|. \]

This proves the lemma. \(\square\)

5. Conditional construction in one field

Fix a totally real field \(K\) satisfying

\[ |\Delta_K|^{1/d}\le D, \qquad R_K\le E^d. \]

Choose constants \(L>T>0\), to be specified later, and set

\[ Y:=\frac{e^{L-T}}4, \qquad M:=\lceil 2Y\rceil, \qquad X:=e^L. \]

Define

\[ C_K=\{M+\beta:\beta\in B_K(Y)\} \]

and

\[ \widetilde A_K=U_K(T)C_K. \]

Finally put

\[ A_K=\sigma_1(\widetilde A_K)\subset\mathbb R. \]

Let

\[ n_K:=|A_K|=|\widetilde A_K|. \]

We now estimate \(n_K\), \(|A_K+A_K|\), and \(|A_KA_K|\).

6. Size of \(A_K\)

Because \(1\in U_K(T)\), we have \(C_K\subset \widetilde A_K\). Also \(|C_K|=|B_K(Y)|\). By Lemma 1,

\[ n_K\ge |C_K| = |B_K(Y)| \ge \frac{Y^d}{\sqrt{|\Delta_K|}}-1. \]

Using \(|\Delta_K|^{1/d}\le D\), for all sufficiently large \(d\),

\[ n_K\ge \left(\frac{Y}{2D^{1/2}}\right)^d. \]

Define

\[ \alpha:=\log\left(\frac{Y}{2D^{1/2}}\right). \]

We will choose \(L,T\) so that \(\alpha>0\). Then

\[ n_K\ge e^{\alpha d} \]

for all large \(d\).

On the other hand, every \(a\in \widetilde A_K\) satisfies \(|\sigma_j(a)|\le X=e^L\). Indeed, if \(a=uc\), with \(u\in U_K(T)\) and \(c=M+\beta\in C_K\), then

\[ |\sigma_j(c)| \le M+|\sigma_j(\beta)| \le 3Y+Y = 4Y, \]

so

\[ |\sigma_j(a)| \le e^T\cdot 4Y = e^T\cdot e^{L-T} = e^L=X. \]

Therefore

\[ \widetilde A_K\subset B_K(X). \]

By Lemma 1,

\[ n_K\le |B_K(X)|\le (2X+1)^d. \]

For \(X\ge1\), this gives

\[ n_K\le (3e^L)^d. \]

Define

\[ \beta:=\log(3e^L)=L+\log 3. \]

Then

\[ n_K\le e^{\beta d}. \]

Thus we have the important size bounds

\[ e^{\alpha d}\le n_K\le e^{\beta d}, \]

for all sufficiently large \(d\).

7. Sumset estimate

Since every \(a\in \widetilde A_K\) satisfies \(|\sigma_j(a)|\le X\), every sum \(a+b\) satisfies

\[ |\sigma_j(a+b)|\le 2X. \]

Hence

\[ \widetilde A_K+\widetilde A_K\subset B_K(2X). \]

By Lemma 1,

\[ |A_K+A_K| = |\widetilde A_K+\widetilde A_K| \le |B_K(2X)| \le (4X+1)^d \le (5e^L)^d. \]

Define

\[ \beta_+:=\log(5e^L)=L+\log 5. \]

Then

\[ |A_K+A_K|\le e^{\beta_+ d}. \]

Using \(n_K\ge e^{\alpha d}\), we get

\[ |A_K+A_K| \le n_K^{\beta_+/\alpha}. \]

Thus the sumset will be bounded by \(n_K^{2-\delta}\) as soon as

\[ \frac{\beta_+}{\alpha}<2. \]

Because

\[ Y=\frac{e^{L-T}}4, \]

we have

\[ \alpha = \log\left(\frac{e^{L-T}}{8D^{1/2}}\right) = L-T-\log(8D^{1/2}). \]

If we choose, say,

\[ T=\frac L4 \]

and then take \(L\) sufficiently large depending only on \(D\), then

\[ \alpha\sim \frac{3L}{4}, \qquad \beta_+\sim L, \]

so

\[ \frac{\beta_+}{\alpha}\to \frac43<2. \]

Therefore there is a positive constant

\[ \delta_{\mathrm{sum}}>0 \]

such that

\[ |A_K+A_K|\le n_K^{2-\delta_{\mathrm{sum}}} \]

for all sufficiently large \(d\).

8. Product set estimate

This is the heart of the method.

Let

\[ U:=U_K(T). \]

Let \(\mathcal P\) be the set of principal ideals of \(\mathcal O_K\) represented by elements of \(\widetilde A_K\):

\[ \mathcal P := \{(a):a\in \widetilde A_K\}. \]

8.1. Each represented ideal has many representatives in \(\widetilde A_K\)

Suppose \(a\in \widetilde A_K\). Then \(a=uc\) for some \(u\in U\), \(c\in C_K\). For every \(v\in U\), the element \(vc\) also lies in \(\widetilde A_K\), and

\[ (vc)=(c)=(uc)=(a). \]

Moreover the elements \(vc\) are distinct as \(v\) varies, because \(c\neq0\).

Therefore each ideal in \(\mathcal P\) has at least \(|U|\) representatives in \(\widetilde A_K\). Hence

\[ |\mathcal P|\le \frac{n_K}{|U|}. \]

8.2. Possible product ideals

If \(z=ab\in \widetilde A_K\widetilde A_K\), then

\[ (z)=(a)(b) \]

with \((a),(b)\in\mathcal P\). Therefore the number of possible principal ideals \((z)\) arising from products is at most

\[ |\mathcal P|^2 \le \left(\frac{n_K}{|U|}\right)^2. \]

8.3. Number of generators per product ideal

We need to bound how many actual elements \(z\in \widetilde A_K\widetilde A_K\) can generate a fixed principal ideal.

First observe that every \(a\in \widetilde A_K\) satisfies both upper and lower bounds at every embedding. We already proved the upper bound

\[ |\sigma_j(a)|\le X=e^L. \]

For the lower bound, if \(a=uc\), with \(u\in U_K(T)\) and \(c=M+\beta\in C_K\), then

\[ |\sigma_j(c)|\ge M-|\sigma_j(\beta)|\ge 2Y-Y=Y, \]

and

\[ |\sigma_j(u)|\ge e^{-T}. \]

Thus

\[ |\sigma_j(a)|\ge Ye^{-T}. \]

Set

\[ \ell:=Ye^{-T}. \]

So for every \(a\in \widetilde A_K\),

\[ \ell\le |\sigma_j(a)|\le X. \]

Therefore every product \(z=ab\) satisfies

\[ \ell^2\le |\sigma_j(z)|\le X^2. \]

Now fix one product \(z_0\in \widetilde A_K\widetilde A_K\). Any other product \(z\in \widetilde A_K\widetilde A_K\) generating the same principal ideal satisfies

\[ z=\varepsilon z_0 \]

for some unit \(\varepsilon\in\mathcal O_K^\times\). For each embedding,

\[ |\sigma_j(\varepsilon)| = \frac{|\sigma_j(z)|}{|\sigma_j(z_0)|} \le \frac{X^2}{\ell^2} = \left(\frac X\ell\right)^2. \]

Similarly,

\[ |\sigma_j(\varepsilon)|\ge \left(\frac \ell X\right)^2. \]

Thus

\[ |\log|\sigma_j(\varepsilon)||\le 2\log(X/\ell). \]

Compute

\[ \ell=Ye^{-T} = \frac{e^{L-T}}4 e^{-T} = \frac{e^{L-2T}}4. \]

Therefore

\[ \frac X\ell = \frac{e^L}{e^{L-2T}/4} = 4e^{2T}. \]

So

\[ 2\log(X/\ell) = 2\log(4e^{2T}) = 4T+\log 16. \]

Define

\[ S:=4T+\log 16. \]

Then all quotient units \(\varepsilon\) lie in \(U_K(S)\). Hence each fixed product ideal contributes at most \(|U_K(S)|\) elements to the product set.

Combining this with the ideal count gives

\[ |\widetilde A_K\widetilde A_K| \le \left(\frac{n_K}{|U_K(T)|}\right)^2 |U_K(S)|. \]

By Lemma 3, since \(S/T\) is bounded absolutely once \(T\ge1\), there is an absolute constant \(q_0\) such that

\[ |U_K(S)|\le q_0^d |U_K(T)|. \]

For example, taking \(T\) large enough, one may use some fixed \(q_0\), say \(q_0=20\).

Thus

\[ |\widetilde A_K\widetilde A_K| \le n_K^2 \frac{q_0^d}{|U_K(T)|}. \]

8.4. Lower bound for \(|U_K(T)|\)

By Lemma 2 and \(R_K\le E^d\), for fixed sufficiently large \(T\),

\[ |U_K(T)| \ge \left(\frac{c_UT}{E}\right)^d \]

for all sufficiently large \(d\).

Choose \(T\) so large that

\[ \frac{c_UT}{E}>q_0. \]

Define

\[ \eta:= \log\left(\frac{c_UT}{Eq_0}\right)>0. \]

Then

\[ \frac{q_0^d}{|U_K(T)|} \le e^{-\eta d}. \]

Therefore

\[ |\widetilde A_K\widetilde A_K| \le n_K^2 e^{-\eta d}. \]

Since \(n_K\le e^{\beta d}\), we have

\[ d\ge \frac{\log n_K}{\beta}. \]

Hence

\[ e^{-\eta d} \le n_K^{-\eta/\beta}. \]

So

\[ |A_KA_K| = |\widetilde A_K\widetilde A_K| \le n_K^{2-\eta/\beta}. \]

Thus the product set satisfies

\[ |A_KA_K|\le n_K^{2-\delta_{\mathrm{prod}}}, \]

where

\[ \delta_{\mathrm{prod}}:=\frac{\eta}{\beta}>0. \]

9. Choosing parameters

Take

\[ T=\frac L4. \]

We need \(L\) large enough so that:

  1. \(Y=e^{L-T}/4=e^{3L/4}/4\) is large compared to \(D^{1/2}\), so that

    \[ \alpha = \log\left(\frac{Y}{2D^{1/2}}\right)>0. \]

  2. The sumset exponent is \(<2\), i.e.

    \[ \frac{\beta_+}{\alpha}<2. \]

    Since \(\beta_+\sim L\) and \(\alpha\sim 3L/4\), this holds for large \(L\).

  3. The unit saving beats the dilation loss:

    \[ \frac{c_UT}{E}>q_0. \]

    Since \(T=L/4\), this also holds for large \(L\).

After choosing such an \(L\), define

\[ \delta := \frac12 \min\left\{ 2-\frac{\beta_+}{\alpha}, \frac{\eta}{\beta} \right\} >0. \]

The factor \(1/2\) is only to absorb the harmless floor and \(O(1)\) errors from the lattice-counting estimates.

Then, for every sufficiently large degree \(d\) in our arithmetic family,

\[ |A_K+A_K|\le |A_K|^{2-\delta} \]

and

\[ |A_KA_K|\le |A_K|^{2-\delta}. \]

10. Producing the infinite sequence

Let \(K_i\) be the totally real fields from the arithmetic input, with \(d_i\to\infty\). For each \(K_i\), construct \(A_i:=A_{K_i}\subset\mathbb R\) as above.

Because

\[ |A_i|\ge e^{\alpha d_i}, \]

we have \(|A_i|\to\infty\). After discarding finitely many initial fields to remove small-degree edge effects, we obtain

\[ \max(|A_i+A_i|,|A_iA_i|) \le |A_i|^{2-\delta} \]

for every \(i\), with one absolute \(\delta>0\).

This completes the conditional construction.

11. Precise remaining gaps and their status

The main body of the argument above reduces the theorem to a concrete arithmetic supply statement. Here are the gaps, precisely stated.

Gap 1: Good totally real field tower

Needed statement

There exist absolute constants \(D,E>1\) and infinitely many totally real fields \(K_i\) with \(d_i=[K_i:\mathbb Q]\to\infty\) such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

and

\[ R_{K_i}\le E^{d_i}. \]

Status

This should be closable using standard algebraic number theory.

  • Bounded root discriminant comes from an infinite totally real narrow Hilbert class field tower.
  • The regulator bound follows from the analytic class number formula plus standard residue estimates for Dedekind zeta-functions.

This is a deep input, but not a conceptual obstruction to the approach.

Seriousness

Moderate but standard. If one insists on a self-contained proof, this is the largest arithmetic component to fill in. If one is allowed to invoke known class field tower results, the gap is essentially closed.

Gap 2: Normalization of regulator and unit lattice volume

Needed statement

For the logarithmic unit lattice

\[ \Lambda_K=\lambda(\mathcal O_K^\times)\subset H_d, \]

one needs the lower bound

\[ |\Lambda_K\cap[-T,T]^d| \ge \frac{(cT)^{d-1}}{R_K}-1. \]

Status

This follows from Blichfeldt’s principle and the elementary fact that the central section

\[ H_d\cap[-T,T]^d \]

has \((d-1)\)-volume at least \(c^dT^{d-1}\). The proof was given above up to harmless normalization constants.

Seriousness

Low. This is routine geometry of numbers.

Gap 3: Additive box lower bound

Needed statement

For

\[ B_K(Z)=\{\alpha\in\mathcal O_K:|\sigma_j(\alpha)|\le Z\ \forall j\}, \]

one needs

\[ |B_K(Z)|\ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

Status

This follows directly from Blichfeldt’s principle in the Minkowski lattice \(\sigma(\mathcal O_K)\). The proof was given above.

Seriousness

Low.

Gap 4: Product-ideal counting

Needed statement

For

\[ \widetilde A_K=U_K(T)C_K, \]

one needs

\[ |\widetilde A_K\widetilde A_K| \le |\widetilde A_K|^2 \frac{q_0^d}{|U_K(T)|}. \]

Status

This was proved above. The key ingredients are:

  1. each represented principal ideal has at least \(|U_K(T)|\) representatives in \(\widetilde A_K\);
  2. each product ideal contributes at most \(|U_K(S)|\) generators;
  3. \(|U_K(S)|\le q_0^d|U_K(T)|\).

Seriousness

Low to moderate, but the proof is conceptually clean and should be robust.

12. Why this approach is more promising than other natural attempts

It is worth emphasizing why the number-field/unit strategy is preferable to more naive constructions.

Smooth integers

Taking \(A\) to be smooth numbers or multiplication-table sets inside \([1,X]\) gives small sumset because \(A\subset[1,X]\), and somewhat small product set because smooth numbers are multiplicatively structured. But known Dickman-type estimates only give savings of order

\[ |A|^2 / |A|^{o(1)}, \]

not a fixed power saving. This is too weak.

Boolean cubes / finite rings

A Boolean cube in a direct product ring would give extremely small sumset and product set. But \(\mathbb R\) has no zero divisors, so one cannot literally embed such a product ring into \(\mathbb R\). The number-field construction imitates part of this effect through the many archimedean coordinates and unit symmetries, while staying inside a field.

Finite-field templates

Finite fields have sets with sumset and product set of size \(O(|A|)\), but characteristic obstructions prevent directly lifting their full additive and multiplicative tables to characteristic zero. The number-field construction avoids characteristic issues entirely.

13. Summary of the proof plan

The plan can be summarized in five steps.

Step 1: Choose good totally real fields

Take \(K_i\) totally real with

\[ d_i\to\infty, \qquad |\Delta_{K_i}|^{1/d_i}\le D, \qquad R_{K_i}\le E^{d_i}. \]

Step 2: Choose fixed archimedean parameters

Fix large constants \(L>T>0\), with \(T=L/4\), chosen so that the later inequalities hold.

Set

\[ Y=\frac{e^{L-T}}4, \qquad M=\lceil 2Y\rceil. \]

Step 3: Build a shifted core

Define

\[ C_i = \{M+\beta:\beta\in\mathcal O_{K_i}, |\sigma_j(\beta)|\le Y\ \forall j\}. \]

The shift by \(M\) ensures every conjugate of every element of \(C_i\) is bounded both above and below.

Step 4: Saturate by small units

Define

\[ \widetilde A_i = U_{K_i}(T)C_i. \]

Then set

\[ A_i=\sigma_1(\widetilde A_i)\subset\mathbb R. \]

Step 5: Count

  • Size:
\[ |A_i|\asymp \exp(\Theta(d_i)). \]
  • Sumset:
\[ A_i+A_i \]

lies in an archimedean box of fixed radius, so

\[ |A_i+A_i|\le \exp(\beta_+d_i) \le |A_i|^{2-\delta}. \]
  • Product set:

The unit saturation gives many representatives of the same principal ideals, forcing multiplicative collisions:

\[ |A_iA_i| \le |A_i|^2\exp(-\eta d_i) \le |A_i|^{2-\delta}. \]

Thus the construction yields an infinite sequence of finite subsets of \(\mathbb R\) with

\[ \max(|A_i+A_i|,|A_iA_i|) \le |A_i|^{2-\delta}. \]

The key remaining task for a fully polished proof is to write out the standard arithmetic input carefully, especially the construction of the totally real bounded-root-discriminant tower and the regulator bound.

The proof uses two standard arithmetic inputs:

  1. Martinet’s theorem: there are infinite totally real class-field towers, hence infinitely many totally real fields of unbounded degree and bounded root discriminant.
  2. Landau–Stark residue bound for Dedekind zeta functions, which implies that along any bounded-root-discriminant family, the regulator is at most exponential in the degree.

Throughout, all logarithms are natural.

1. Arithmetic supply theorem

For a number field \(K\), write

\[ d_K=[K:\mathbb Q],\qquad \Delta_K=\text{absolute discriminant of }K, \qquad \operatorname{rd}(K)=|\Delta_K|^{1/d_K}. \]

We need the following standard consequence of Martinet’s class-field tower construction.

Proposition 1.1: Totally real fields with bounded root discriminant and exponential regulator

There exist absolute constants \(D,E>1\) and an infinite sequence of totally real fields \(K_i\) such that, with \(d_i=[K_i:\mathbb Q]\),

\[ d_i\to\infty, \]

and for every \(i\),

\[ |\Delta_{K_i}|^{1/d_i}\le D, \]

and

\[ R_{K_i}\le E^{d_i}, \]

where \(R_{K_i}\) denotes the regulator.

Proof

Martinet proved that there exists a totally real number field \(K_0\) with an infinite narrow Hilbert class-field tower. Let

\[ K_0\subset K_1\subset K_2\subset\cdots \]

be such a tower. Since the tower is narrow, all infinite places split completely at every step, so every \(K_i\) is totally real. Since each extension \(K_{i+1}/K_i\) is unramified at all finite primes, the relative discriminant is trivial. Therefore

\[ |\Delta_{K_i}| = |\Delta_{K_0}|^{[K_i:K_0]}. \]

Hence

\[ |\Delta_{K_i}|^{1/[K_i:\mathbb Q]} = |\Delta_{K_0}|^{1/[K_0:\mathbb Q]} =:D. \]

The tower is infinite, so \(d_i=[K_i:\mathbb Q]\to\infty\).

It remains to record the regulator bound. We use the following weak form of the Landau–Stark residue estimate: there is an absolute constant \(C_{\mathrm{LS}}>0\) such that for every number field \(F\) of degree \(d_F\ge2\),

\[ \operatorname*{Res}_{s=1}\zeta_F(s) \le \left( C_{\mathrm{LS}} \max\left\{1,\frac{\log|\Delta_F|}{d_F}\right\} \right)^{d_F}. \]

This follows, for example, from Landau’s classical bound

\[ \operatorname*{Res}_{s=1}\zeta_F(s) \le \left( \frac{e\log|\Delta_F|}{2(d_F-1)} \right)^{d_F-1} \]

after adjusting constants for small degrees.

For a totally real field \(F\) of degree \(d_F\), the analytic class number formula gives

\[ \operatorname*{Res}_{s=1}\zeta_F(s) = \frac{2^{d_F-1}h_FR_F}{\sqrt{|\Delta_F|}}, \]

because the only roots of unity in \(F\) are \(\pm1\). Thus

\[ R_F \le h_FR_F = 2^{1-d_F}\sqrt{|\Delta_F|} \operatorname*{Res}_{s=1}\zeta_F(s). \]

For the fields \(K_i\), we have

\[ \frac{\log|\Delta_{K_i}|}{d_i} = \log \operatorname{rd}(K_i) \le \log D. \]

Therefore, for a constant \(C_D\) depending only on \(D\),

\[ \operatorname*{Res}_{s=1}\zeta_{K_i}(s) \le C_D^{d_i}. \]

Also

\[ \sqrt{|\Delta_{K_i}|} \le D^{d_i/2}. \]

Hence

\[ R_{K_i} \le 2^{1-d_i}D^{d_i/2}C_D^{d_i} \le E^{d_i} \]

for some absolute constant \(E>1\), depending only on the fixed Martinet tower.

This proves the proposition. \(\square\)

2. Elementary counting lemmas

Let \(K/\mathbb Q\) be totally real of degree \(d\), with embeddings

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow \mathbb R. \]

For \(Z>0\), define

\[ B_K(Z) := \left\{ \alpha\in\mathcal O_K: |\sigma_j(\alpha)|\le Z \text{ for all }j=1,\dots,d \right\}. \]

For \(t>0\), define the small-unit box

\[ U_K(t) := \left\{ u\in\mathcal O_K^\times: |\log|\sigma_j(u)||\le t \text{ for all }j=1,\dots,d \right\}. \]

Lemma 2.1: Algebraic-integer boxes

For every \(Z>0\),

\[ |B_K(Z)|\le (2Z+1)^d. \]

Also,

\[ |B_K(Z)| \ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

Proof

Embed \(\mathcal O_K\) into \(\mathbb R^d\) by

\[ \alpha\mapsto (\sigma_1(\alpha),\dots,\sigma_d(\alpha)). \]

This is a lattice of covolume \(\sqrt{|\Delta_K|}\).

For the upper bound, if \(\alpha\neq\beta\in\mathcal O_K\), then \(\gamma=\alpha-\beta\neq0\) is an algebraic integer, so

\[ |N_{K/\mathbb Q}(\gamma)| = \prod_{j=1}^d |\sigma_j(\gamma)| \]

is a positive integer. Hence

\[ \prod_{j=1}^d|\sigma_j(\gamma)|\ge1, \]

so at least one embedding satisfies

\[ |\sigma_j(\gamma)|\ge1. \]

Thus the embedded lattice is \(1\)-separated in the sup norm. The points of \(B_K(Z)\) lie in the cube \([-Z,Z]^d\). Around each such point put an open sup-norm cube of side length \(1\). These cubes are disjoint and lie inside \([-Z-\frac12,Z+\frac12]^d\). Therefore

\[ |B_K(Z)|\le (2Z+1)^d. \]

For the lower bound, apply Blichfeldt’s principle to the cube

\[ [-Z/2,Z/2]^d. \]

Some translate of this cube contains at least

\[ \frac{Z^d}{\sqrt{|\Delta_K|}}-1 \]

lattice points. Taking differences from one fixed lattice point in that translate gives distinct lattice points in

\[ [-Z,Z]^d. \]

Thus

\[ |B_K(Z)| \ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

\(\square\)

Lemma 2.2: Many small units from a regulator bound

For every totally real field \(K\) of degree \(d\ge2\) and every \(t>0\),

\[ |U_K(t)| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

Proof

Consider the logarithmic embedding

\[ \lambda:\mathcal O_K^\times\to H_d, \]

where

\[ H_d=\left\{ x=(x_1,\dots,x_d)\in\mathbb R^d: x_1+\cdots+x_d=0 \right\}, \]

and

\[ \lambda(u) = (\log|\sigma_1(u)|,\dots,\log|\sigma_d(u)|). \]

The image

\[ \Lambda_K:=\lambda(\mathcal O_K^\times) \]

is a lattice in \(H_d\) of rank \(d-1\). With the standard regulator normalization, the Euclidean covolume of \(\Lambda_K\) in \(H_d\) is

\[ \sqrt d\,R_K. \]

For \(r>0\), put

\[ Q_r:=H_d\cap[-r,r]^d. \]

We first lower-bound the \((d-1)\)-dimensional volume of \(Q_r\). Let \(m=d-1\). Parametrize \(H_d\) by

\[ (y_1,\dots,y_m) \mapsto (y_1,\dots,y_m,-y_1-\cdots-y_m). \]

The Jacobian of this map is \(\sqrt d\). Therefore

\[ \operatorname{vol}_{H_d}(Q_r) = \sqrt d\cdot \operatorname{meas} \left\{ y\in[-r,r]^m: |y_1+\cdots+y_m|\le r \right\}. \]

The distribution of \(y_1+\cdots+y_m\), with \(y_i\) uniformly distributed on \([-r,r]\), has an even unimodal density. Therefore among all intervals of length \(2r\), the interval \([-r,r]\) captures maximal mass. Since the support is contained in \([-mr,mr]\), which can be covered by \(m\) intervals of length \(2r\), the central interval captures at least a \(1/m\)-fraction of the total mass. Hence

\[ \operatorname{meas} \left\{ y\in[-r,r]^m: |y_1+\cdots+y_m|\le r \right\} \ge \frac{(2r)^m}{m}. \]

Thus

\[ \operatorname{vol}_{H_d}(Q_r) \ge \sqrt d\,\frac{(2r)^{d-1}}{d-1}. \]

Apply this with \(r=t/2\). Then

\[ \operatorname{vol}_{H_d}(Q_{t/2}) \ge \sqrt d\,\frac{t^{d-1}}{d-1}. \]

By Blichfeldt’s principle, some translate of \(Q_{t/2}\) contains at least

\[ \frac{\operatorname{vol}_{H_d}(Q_{t/2})}{\sqrt d\,R_K}-1 \ge \frac{t^{d-1}}{(d-1)R_K}-1 \]

points of \(\Lambda_K\). Taking differences from one fixed point gives distinct lattice points in

\[ Q_{t/2}-Q_{t/2}=Q_t. \]

Thus

\[ |\Lambda_K\cap Q_t| \ge \frac{t^{d-1}}{(d-1)R_K}-1. \]

Since \(d-1\le 2^{d-1}\), we get

\[ |\Lambda_K\cap Q_t| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

Finally, \(U_K(t)\) is precisely the inverse image of \(\Lambda_K\cap Q_t\) under \(\lambda\), and the kernel of \(\lambda\) is \(\{\pm1\}\). In particular,

\[ |U_K(t)|\ge |\Lambda_K\cap Q_t|. \]

Therefore

\[ |U_K(t)| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

\(\square\)

Lemma 2.3: Unit-box dilation

Let \(0<t\le t'\). Let \(q\) be an integer satisfying

\[ q>\frac{2t'}{t}. \]

Then

\[ |U_K(t')| \le q^{d-1}|U_K(t)| \le q^d|U_K(t)|. \]

Proof

Work in the logarithmic lattice \(\Lambda_K\subset H_d\). As above, put

\[ Q_s:=H_d\cap[-s,s]^d. \]

Partition \(\Lambda_K\cap Q_{t'}\) into residue classes modulo \(q\Lambda_K\). There are exactly \(q^{d-1}\) residue classes.

Fix one residue class and choose \(x_0\in\Lambda_K\cap Q_{t'}\) in that class. If \(x\) is another point in the same class, then

\[ x-x_0=qy \]

for some \(y\in\Lambda_K\). Since \(x,x_0\in Q_{t'}\),

\[ x-x_0\in Q_{2t'}. \]

Therefore

\[ y=\frac{x-x_0}{q}\in Q_{2t'/q}. \]

Because \(q>2t'/t\), we have \(2t'/q<t\), so

\[ y\in Q_t. \]

Thus the map

\[ x\mapsto \frac{x-x_0}{q} \]

injects the chosen residue class into \(\Lambda_K\cap Q_t\). Hence each residue class contributes at most \(|\Lambda_K\cap Q_t|\) points. Therefore

\[ |\Lambda_K\cap Q_{t'}| \le q^{d-1}|\Lambda_K\cap Q_t|. \]

Passing back to units only multiplies both sides by the same kernel size \(|\{\pm1\}|=2\). Hence

\[ |U_K(t')|\le q^{d-1}|U_K(t)|. \]

\(\square\)

3. Choice of global parameters

Let \(D,E>1\) be the constants from Proposition 1.1.

Set

\[ q_0:=20. \]

Choose a real number \(T\ge1\) so large that

\[ T>80E \]

and

\[ 4T+\log 5 < 2\bigl(3T-\log(8\sqrt D)\bigr). \]

This is possible because the left-hand side is asymptotic to \(4T\), while the right-hand side is asymptotic to \(6T\).

Now define

\[ L:=4T, \]
\[ X:=e^L=e^{4T}, \]
\[ Y:=\frac{e^{L-T}}4=\frac{e^{3T}}4, \]

and

\[ M:=\lceil 2Y\rceil. \]

We also define the constants

\[ \alpha := \log\left(\frac{Y}{2\sqrt D}\right) = 3T-\log(8\sqrt D), \]
\[ \beta := \log(3X) = 4T+\log 3, \]

and

\[ \beta_+ := \log(5X) = 4T+\log 5. \]

By the choice of \(T\),

\[ \alpha>0 \]

and

\[ \frac{\beta_+}{\alpha}<2. \]

Define

\[ \delta_{\mathrm{sum}} := 2-\frac{\beta_+}{\alpha} >0. \]

Also set

\[ \rho:=\frac{T}{4E}. \]

Since \(T>80E\),

\[ \rho>20=q_0. \]

Define

\[ \eta:=\log\left(\frac{\rho}{q_0}\right)>0 \]

and

\[ \delta_{\mathrm{prod}} := \frac{\eta}{\beta}>0. \]

Finally put

\[ \delta := \frac12\min\{\delta_{\mathrm{sum}},\delta_{\mathrm{prod}}\}. \]

This is a positive absolute constant.

4. Construction inside one totally real field

Let \(K\) be one of the fields from Proposition 1.1, of degree \(d\), and assume \(d\) is sufficiently large. Let

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow\mathbb R \]

be its real embeddings.

Define

\[ C_K := \left\{ M+\beta: \beta\in B_K(Y) \right\}. \]

Then define

\[ \widetilde A_K := U_K(T)C_K = \{uc:u\in U_K(T),\ c\in C_K\} \subset \mathcal O_K. \]

Finally, choose the first embedding and set

\[ A_K:=\sigma_1(\widetilde A_K)\subset\mathbb R. \]

Since \(\sigma_1\) is injective on \(K\), we have

\[ |A_K|=|\widetilde A_K|, \]
\[ |A_K+A_K| = |\widetilde A_K+\widetilde A_K|, \]

and

\[ |A_KA_K| = |\widetilde A_K\widetilde A_K|. \]

So it suffices to estimate the corresponding sets inside \(K\).

Write

\[ n:=|\widetilde A_K|=|A_K|. \]

5. Archimedean bounds for the elements of \(\widetilde A_K\)

Let \(c\in C_K\). Then

\[ c=M+\beta \]

with \(\beta\in B_K(Y)\). Hence for every embedding \(\sigma_j\),

\[ |\sigma_j(\beta)|\le Y. \]

Since \(M\ge 2Y\),

\[ \sigma_j(c) = M+\sigma_j(\beta) \ge M-Y \ge Y. \]

Also, since \(Y\ge1\) and \(M=\lceil2Y\rceil\le2Y+1\le3Y\),

\[ |\sigma_j(c)| \le M+|\sigma_j(\beta)| \le 3Y+Y = 4Y. \]

Thus

\[ Y\le |\sigma_j(c)|\le 4Y \]

for every \(j\).

If \(a\in\widetilde A_K\), then \(a=uc\) with \(u\in U_K(T)\) and \(c\in C_K\). Since

\[ e^{-T}\le |\sigma_j(u)|\le e^T, \]

we obtain

\[ Ye^{-T} \le |\sigma_j(a)| \le 4Ye^T. \]

By the definition of \(Y\),

\[ 4Ye^T = 4\cdot\frac{e^{L-T}}4\cdot e^T = e^L = X. \]

Therefore every \(a\in\widetilde A_K\) satisfies

\[ |\sigma_j(a)|\le X \qquad\text{for every }j. \]

We shall also use the lower bound

\[ |\sigma_j(a)|\ge \ell, \]

where

\[ \ell:=Ye^{-T}. \]

Since \(Y=e^{3T}/4\), we have

\[ \ell=\frac{e^{2T}}4. \]

6. Size of \(A_K\)

Because \(1\in U_K(T)\), we have

\[ C_K\subset \widetilde A_K. \]

Therefore

\[ n \ge |C_K| = |B_K(Y)|. \]

By Lemma 2.1,

\[ |B_K(Y)| \ge \frac{Y^d}{\sqrt{|\Delta_K|}}-1. \]

Since

\[ |\Delta_K|^{1/d}\le D, \]

we have

\[ \sqrt{|\Delta_K|} \le D^{d/2}. \]

Thus

\[ |B_K(Y)| \ge \left(\frac{Y}{\sqrt D}\right)^d-1. \]

Because \(\alpha>0\), we have \(Y/(2\sqrt D)>1\). Hence, for all sufficiently large \(d\),

\[ \left(\frac{Y}{\sqrt D}\right)^d-1 \ge \left(\frac{Y}{2\sqrt D}\right)^d = e^{\alpha d}. \]

Thus

\[ n\ge e^{\alpha d}. \tag{6.1} \]

On the other hand, we have already shown that

\[ \widetilde A_K\subset B_K(X). \]

By Lemma 2.1,

\[ n \le |B_K(X)| \le (2X+1)^d. \]

Since \(X\ge1\),

\[ 2X+1\le3X. \]

Therefore

\[ n\le (3X)^d=e^{\beta d}. \tag{6.2} \]

7. Sumset estimate

For \(a,b\in\widetilde A_K\), and for each embedding \(\sigma_j\),

\[ |\sigma_j(a+b)| \le |\sigma_j(a)|+|\sigma_j(b)| \le 2X. \]

Therefore

\[ \widetilde A_K+\widetilde A_K\subset B_K(2X). \]

By Lemma 2.1,

\[ |\widetilde A_K+\widetilde A_K| \le |B_K(2X)| \le (4X+1)^d. \]

Since \(X\ge1\),

\[ 4X+1\le5X. \]

Thus

\[ |A_K+A_K| = |\widetilde A_K+\widetilde A_K| \le (5X)^d = e^{\beta_+d}. \]

Using \(n\ge e^{\alpha d}\), we get

\[ e^{\beta_+d} \le n^{\beta_+/\alpha}. \]

Hence

\[ |A_K+A_K| \le n^{\beta_+/\alpha} = n^{2-\delta_{\mathrm{sum}}}. \]

Since \(\delta\le\delta_{\mathrm{sum}}\),

\[ |A_K+A_K| \le n^{2-\delta}. \tag{7.1} \]

8. Product set estimate

This is the main collision argument.

Let

\[ U:=U_K(T). \]

Let \(\mathcal P\) denote the set of principal ideals represented by elements of \(\widetilde A_K\):

\[ \mathcal P := \{(a):a\in\widetilde A_K\}. \]

8.1. Each represented ideal has many representatives

Take any ideal \(I\in\mathcal P\). By definition, there is some

\[ a\in\widetilde A_K \]

with

\[ I=(a). \]

Write

\[ a=uc, \qquad u\in U,\ c\in C_K. \]

Since \(u\) is a unit,

\[ (a)=(c). \]

For every \(v\in U\), we have

\[ vc\in U C_K=\widetilde A_K, \]

and

\[ (vc)=(c)=I. \]

Moreover, the elements \(vc\) are distinct as \(v\) varies, because \(c\neq0\). Indeed, every embedding of \(c\) has absolute value at least \(Y>0\).

Thus each ideal in \(\mathcal P\) has at least \(|U|\) representatives in \(\widetilde A_K\). Therefore

\[ |\mathcal P| \le \frac{n}{|U|}. \tag{8.1} \]

8.2. Number of possible product ideals

If

\[ z=ab\in\widetilde A_K\widetilde A_K, \]

then

\[ (z)=(a)(b), \]

with \((a),(b)\in\mathcal P\). Hence the number of principal ideals represented by products is at most

\[ |\mathcal P|^2. \]

By (8.1), this is at most

\[ \left(\frac{n}{|U|}\right)^2. \tag{8.2} \]

8.3. Number of generators per product ideal

Recall that every \(a\in\widetilde A_K\) satisfies

\[ \ell\le |\sigma_j(a)|\le X \]

for every \(j\), where

\[ \ell=Ye^{-T}. \]

Therefore every product \(z=ab\) satisfies

\[ \ell^2 \le |\sigma_j(z)| \le X^2 \]

for every \(j\).

Fix a product ideal \(J\) represented by some product

\[ z_0\in\widetilde A_K\widetilde A_K. \]

If another product \(z\in\widetilde A_K\widetilde A_K\) generates the same ideal \(J\), then

\[ (z)=(z_0), \]

so

\[ z=\varepsilon z_0 \]

for some unit \(\varepsilon\in\mathcal O_K^\times\).

For each embedding \(\sigma_j\),

\[ |\sigma_j(\varepsilon)| = \frac{|\sigma_j(z)|}{|\sigma_j(z_0)|}. \]

Since both \(z\) and \(z_0\) have all conjugates between \(\ell^2\) and \(X^2\), we get

\[ \frac{\ell^2}{X^2} \le |\sigma_j(\varepsilon)| \le \frac{X^2}{\ell^2}. \]

Thus

\[ |\log|\sigma_j(\varepsilon)||\le 2\log(X/\ell). \]

Now

\[ X=4Ye^T, \qquad \ell=Ye^{-T}. \]

Hence

\[ \frac{X}{\ell} = 4e^{2T}. \]

Therefore

\[ 2\log(X/\ell) = 2\log(4e^{2T}) = 4T+\log16. \]

Define

\[ S:=4T+\log16. \]

Then every such quotient unit \(\varepsilon\) lies in

\[ U_K(S). \]

Hence each product ideal contributes at most \(|U_K(S)|\) elements to the product set. Combining this with (8.2),

\[ |\widetilde A_K\widetilde A_K| \le \left(\frac{n}{|U_K(T)|}\right)^2 |U_K(S)|. \tag{8.3} \]

8.4. Comparing \(U_K(S)\) and \(U_K(T)\)

Since

\[ S=4T+\log16, \]

and \(T\ge1\), we have

\[ \frac{S}{T} = 4+\frac{\log16}{T} < 7. \]

Therefore

\[ 20>\frac{2S}{T}. \]

By Lemma 2.3 with \(q=20\),

\[ |U_K(S)| \le 20^d |U_K(T)|. \]

Substituting into (8.3),

\[ |\widetilde A_K\widetilde A_K| \le n^2\frac{20^d}{|U_K(T)|}. \tag{8.4} \]

8.5. Lower bound for \(|U_K(T)|\)

By Lemma 2.2,

\[ |U_K(T)| \ge \frac{(T/2)^{d-1}}{R_K}-1. \]

By Proposition 1.1,

\[ R_K\le E^d. \]

Therefore

\[ |U_K(T)| \ge \frac{(T/2)^{d-1}}{E^d}-1. \]

Recall that

\[ \rho=\frac{T}{4E}. \]

Then

\[ \frac{(T/2)^{d-1}}{E^d} = \frac{(2\rho)^{d-1}}{E}. \]

Since \(\rho>1\), the ratio

\[ \frac{(2\rho)^{d-1}/E}{\rho^d} = \frac{2^{d-1}}{E\rho} \]

tends to infinity as \(d\to\infty\). Hence, for all sufficiently large \(d\),

\[ |U_K(T)|\ge \rho^d. \tag{8.5} \]

Combining (8.4) and (8.5),

\[ |\widetilde A_K\widetilde A_K| \le n^2\left(\frac{20}{\rho}\right)^d. \]

Since \(20=q_0\) and

\[ \eta=\log\left(\frac{\rho}{20}\right)>0, \]

this becomes

\[ |\widetilde A_K\widetilde A_K| \le n^2 e^{-\eta d}. \tag{8.6} \]

Using the upper size bound \(n\le e^{\beta d}\), we have

\[ d\ge \frac{\log n}{\beta}. \]

Thus

\[ e^{-\eta d} \le e^{-(\eta/\beta)\log n} = n^{-\eta/\beta}. \]

Therefore

\[ |A_KA_K| = |\widetilde A_K\widetilde A_K| \le n^{2-\eta/\beta} = n^{2-\delta_{\mathrm{prod}}}. \]

Since \(\delta\le\delta_{\mathrm{prod}}\),

\[ |A_KA_K| \le n^{2-\delta}. \tag{8.7} \]

9. Completion of the construction

Let \(K_i\) be the sequence of totally real fields from Proposition 1.1. For every sufficiently large \(i\), construct

\[ A_i:=A_{K_i}\subset\mathbb R \]

as above.

The degree \(d_i=[K_i:\mathbb Q]\) tends to infinity, and by (6.1),

\[ |A_i| \ge e^{\alpha d_i}. \]

Since \(\alpha>0\), this implies

\[ |A_i|\to\infty. \]

After discarding finitely many initial fields and reindexing, estimates (7.1) and (8.7) hold for every \(i\). Therefore, for every \(i\),

\[ |A_i+A_i|\le |A_i|^{2-\delta}, \]

and

\[ |A_iA_i|\le |A_i|^{2-\delta}. \]

Hence

\[ \max\bigl(|A_i+A_i|,\ |A_iA_i|\bigr) \le |A_i|^{2-\delta} \]

for all \(i\), with one absolute constant \(\delta>0\), and with \(|A_i|\to\infty\).

This proves the theorem. \(\square\)

0. Audit of the previous proof

The strategy is sound, but the previous version had a few points that needed tightening:

  1. The existence of totally real fields with bounded root discriminant and exponentially bounded regulator was left as an informal arithmetic input. Below it is stated precisely and derived from Martinet’s totally real class-field tower theorem plus Landau’s residue bound and the analytic class number formula.
  2. The logarithmic unit lattice does not have covolume exactly \(R_K\) in the Euclidean metric on the hyperplane; it has covolume \(\sqrt d\,R_K\). This factor is accounted for.
  3. The lower bound for the number of small units needs a uniform lower bound for the volume of a central cube section. This is proved explicitly.
  4. The product-set argument must carefully count principal ideals and then generators per ideal. This is done below with all constants fixed.

We now give the complete proof.

1. Arithmetic input

We use two standard theorems.

Theorem A: Martinet

There exists an absolute constant \(D>1\) and an infinite sequence of totally real number fields \(K_i\) with

\[ d_i=[K_i:\mathbb Q]\to\infty \]

such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

for every \(i\).

This follows from Martinet’s construction of an infinite totally real class-field tower.

Theorem B: Landau residue bound

There is an absolute constant \(C_L>0\) such that for every number field \(K\) of degree \(d\ge2\),

\[ \operatorname*{Res}_{s=1}\zeta_K(s) \le \left(C_L\left(1+\frac{\log|\Delta_K|}{d}\right)\right)^d. \]

For fields with bounded root discriminant this gives an exponential-in-\(d\) bound for the residue.

Lemma 1.1: Exponential regulator bound

There are absolute constants \(D,E>1\) and infinitely many totally real fields \(K_i\), with \(d_i=[K_i:\mathbb Q]\to\infty\), such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

and

\[ R_{K_i}\le E^{d_i}. \]

Proof

Take \(K_i\) from Theorem A, so

\[ |\Delta_{K_i}|^{1/d_i}\le D. \]

Let

\[ \kappa_{K_i}:=\operatorname*{Res}_{s=1}\zeta_{K_i}(s). \]

By Theorem B,

\[ \kappa_{K_i} \le \left(C_L(1+\log D)\right)^{d_i} =:C_D^{d_i}. \]

For a totally real field \(K\) of degree \(d\), the analytic class number formula says

\[ \kappa_K = \frac{2^{d-1}h_KR_K}{\sqrt{|\Delta_K|}}. \]

Therefore

\[ R_K \le h_KR_K = 2^{1-d}\sqrt{|\Delta_K|}\,\kappa_K. \]

For \(K=K_i\),

\[ \sqrt{|\Delta_{K_i}|}\le D^{d_i/2}, \]

so

\[ R_{K_i} \le 2^{1-d_i}D^{d_i/2}C_D^{d_i} \le E^{d_i} \]

for some fixed \(E>1\), for example

\[ E:=D^{1/2}C_D+1. \]

Thus the sequence satisfies both desired bounds. \(\square\)

2. Geometry-of-numbers estimates

Let \(K/\mathbb Q\) be totally real of degree \(d\). Let

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow\mathbb R \]

be its real embeddings.

For \(Z>0\), define

\[ B_K(Z) := \left\{ \alpha\in\mathcal O_K: |\sigma_j(\alpha)|\le Z \text{ for all }j \right\}. \]

For \(t>0\), define

\[ U_K(t) := \left\{ u\in\mathcal O_K^\times: |\log|\sigma_j(u)||\le t \text{ for all }j \right\}. \]

Lemma 2.1: Algebraic-integer box bounds

For every \(Z>0\),

\[ |B_K(Z)|\le (2Z+1)^d. \]

Also,

\[ |B_K(Z)| \ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

Proof

Embed \(\mathcal O_K\) into \(\mathbb R^d\) by

\[ \alpha\mapsto (\sigma_1(\alpha),\dots,\sigma_d(\alpha)). \]

This is a lattice of covolume \(\sqrt{|\Delta_K|}\).

For the upper bound, if \(\alpha\ne\beta\), then \(\gamma=\alpha-\beta\ne0\) is an algebraic integer, so

\[ |N_{K/\mathbb Q}(\gamma)| = \prod_{j=1}^d |\sigma_j(\gamma)| \]

is a positive integer. Hence at least one \(|\sigma_j(\gamma)|\ge1\). Thus the embedded lattice is \(1\)-separated in the sup norm.

The points of \(B_K(Z)\) lie in \([-Z,Z]^d\). Open sup-norm cubes of side length \(1\) centered at these points are disjoint and lie inside \([-Z-\frac12,Z+\frac12]^d\). Therefore

\[ |B_K(Z)|\le (2Z+1)^d. \]

For the lower bound, apply Blichfeldt’s principle to

\[ [-Z/2,Z/2]^d. \]

Some translate contains at least

\[ \frac{Z^d}{\sqrt{|\Delta_K|}}-1 \]

lattice points. Taking differences from one fixed point in that translate gives distinct lattice points in \([-Z,Z]^d\). Thus

\[ |B_K(Z)| \ge \frac{Z^d}{\sqrt{|\Delta_K|}}-1. \]

\(\square\)

Lemma 2.2: Many small units

For every totally real field \(K\) of degree \(d\ge2\) and every \(t>0\),

\[ |U_K(t)| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

Proof

Consider the logarithmic embedding

\[ \lambda:\mathcal O_K^\times\to H_d, \qquad u\mapsto (\log|\sigma_1(u)|,\dots,\log|\sigma_d(u)|), \]

where

\[ H_d= \left\{ x\in\mathbb R^d: x_1+\cdots+x_d=0 \right\}. \]

By Dirichlet’s unit theorem, the image \(\Lambda_K:=\lambda(\mathcal O_K^\times)\) is a lattice in \(H_d\) of rank \(d-1\). With the usual regulator normalization, its Euclidean covolume in \(H_d\) is

\[ \sqrt d\,R_K. \]

For \(r>0\), set

\[ Q_r:=H_d\cap[-r,r]^d. \]

We need a lower bound for the \((d-1)\)-dimensional volume of \(Q_r\). Put \(m=d-1\), and parametrize \(H_d\) by

\[ (y_1,\dots,y_m) \mapsto (y_1,\dots,y_m,-y_1-\cdots-y_m). \]

The Jacobian is \(\sqrt d\). Hence

\[ \operatorname{vol}_{H_d}(Q_r) = \sqrt d\, \operatorname{meas} \left\{ y\in[-r,r]^m: |y_1+\cdots+y_m|\le r \right\}. \]

Let \(Y_1,\dots,Y_m\) be independent uniform random variables on \([-r,r]\). The density of \(Y_1+\cdots+Y_m\) is even and unimodal. Therefore among intervals of length \(2r\), the interval \([-r,r]\) has maximal probability. The support is \([-mr,mr]\), which can be covered by \(m\) intervals of length \(2r\). Hence

\[ \mathbb P(|Y_1+\cdots+Y_m|\le r)\ge \frac1m. \]

Thus

\[ \operatorname{vol}_{H_d}(Q_r) \ge \sqrt d\,\frac{(2r)^m}{m} = \sqrt d\,\frac{(2r)^{d-1}}{d-1}. \]

Apply this with \(r=t/2\). Then

\[ \operatorname{vol}_{H_d}(Q_{t/2}) \ge \sqrt d\,\frac{t^{d-1}}{d-1}. \]

By Blichfeldt’s principle in the lattice \(\Lambda_K\subset H_d\), some translate of \(Q_{t/2}\) contains at least

\[ \frac{\operatorname{vol}_{H_d}(Q_{t/2})}{\sqrt d\,R_K}-1 \]

lattice points. Taking differences from one fixed point gives distinct lattice points in

\[ Q_{t/2}-Q_{t/2}\subset Q_t. \]

Therefore

\[ |\Lambda_K\cap Q_t| \ge \frac{t^{d-1}}{(d-1)R_K}-1. \]

Since \(d-1\le 2^{d-1}\),

\[ |\Lambda_K\cap Q_t| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

Finally, \(U_K(t)\) is the preimage of \(\Lambda_K\cap Q_t\) under \(\lambda\). The kernel consists of \(\{\pm1\}\), so in particular

\[ |U_K(t)|\ge |\Lambda_K\cap Q_t|. \]

Hence

\[ |U_K(t)| \ge \frac{(t/2)^{d-1}}{R_K}-1. \]

\(\square\)

Lemma 2.3: Dilation of unit boxes

Let \(0<t\le t'\). If \(q\) is an integer satisfying

\[ q>\frac{2t'}{t}, \]

then

\[ |U_K(t')|\le q^{d-1}|U_K(t)|. \]

Proof

Work in the logarithmic lattice \(\Lambda_K\subset H_d\). As above, write

\[ Q_s=H_d\cap[-s,s]^d. \]

Partition \(\Lambda_K\cap Q_{t'}\) into residue classes modulo \(q\Lambda_K\). There are \(q^{d-1}\) such classes.

Fix one nonempty class and choose \(x_0\) in it. For any other \(x\) in the same class,

\[ x-x_0=qy \]

for some \(y\in\Lambda_K\). Since \(x,x_0\in Q_{t'}\),

\[ x-x_0\in Q_{2t'}. \]

Thus

\[ y\in Q_{2t'/q}\subset Q_t. \]

So each residue class contributes at most \(|\Lambda_K\cap Q_t|\) points. Therefore

\[ |\Lambda_K\cap Q_{t'}| \le q^{d-1}|\Lambda_K\cap Q_t|. \]

Since the kernel of the logarithmic map is \(\{\pm1\}\), the same inequality holds for units:

\[ |U_K(t')|\le q^{d-1}|U_K(t)|. \]

\(\square\)

3. Choice of constants

Let \(D,E\) be the constants from Lemma 1.1.

Choose \(T\ge1\) so large that

\[ T>80E \]

and

\[ 4T+\log 5 < 2\bigl(3T-\log(8\sqrt D)\bigr). \]

This is possible because the left side is asymptotic to \(4T\), while the right side is asymptotic to \(6T\).

Set

\[ L:=4T, \qquad X:=e^L=e^{4T}, \]
\[ Y:=\frac{e^{L-T}}4=\frac{e^{3T}}4, \]

and

\[ M:=\lceil 2Y\rceil. \]

Define

\[ \alpha := \log\left(\frac{Y}{2\sqrt D}\right) = 3T-\log(8\sqrt D), \]
\[ \beta := \log(3X) = 4T+\log3, \]

and

\[ \beta_+ := \log(5X) = 4T+\log5. \]

By our choice of \(T\),

\[ \alpha>0 \]

and

\[ \frac{\beta_+}{\alpha}<2. \]

Let

\[ \delta_{\mathrm{sum}} := 2-\frac{\beta_+}{\alpha} >0. \]

Next set

\[ \rho:=\frac{T}{4E}. \]

Since \(T>80E\),

\[ \rho>20. \]

Define

\[ \eta:=\log\left(\frac{\rho}{20}\right)>0 \]

and

\[ \delta_{\mathrm{prod}} := \frac{\eta}{\beta}>0. \]

Finally, define

\[ \delta := \frac12\min\{\delta_{\mathrm{sum}},\delta_{\mathrm{prod}}\}. \]

This is a positive absolute constant.

4. Construction in one field

Let \(K\) be one of the totally real fields from Lemma 1.1, of degree

\[ d=[K:\mathbb Q]. \]

Assume \(d\) is sufficiently large; later we discard finitely many fields.

Define

\[ C_K := \left\{ M+\beta: \beta\in B_K(Y) \right\}. \]

Define

\[ \widetilde A_K := U_K(T)C_K = \{uc:u\in U_K(T),\ c\in C_K\} \subset\mathcal O_K. \]

Finally, fix the first real embedding and put

\[ A_K:=\sigma_1(\widetilde A_K)\subset\mathbb R. \]

Because \(\sigma_1\) is an injective ring homomorphism, it preserves all additive and multiplicative relations. Hence

\[ |A_K|=|\widetilde A_K|, \]
\[ |A_K+A_K|=|\widetilde A_K+\widetilde A_K|, \]

and

\[ |A_KA_K|=|\widetilde A_K\widetilde A_K|. \]

Write

\[ n:=|A_K|=|\widetilde A_K|. \]

5. Basic archimedean bounds

Let \(c\in C_K\). Then

\[ c=M+\beta \]

for some \(\beta\in B_K(Y)\). Thus for every embedding \(\sigma_j\),

\[ |\sigma_j(\beta)|\le Y. \]

Since \(M\ge2Y\),

\[ \sigma_j(c) = M+\sigma_j(\beta) \ge M-Y \ge Y. \]

Also \(Y\ge1\), so

\[ M=\lceil2Y\rceil\le2Y+1\le3Y. \]

Hence

\[ |\sigma_j(c)| \le M+|\sigma_j(\beta)| \le 3Y+Y = 4Y. \]

Thus

\[ Y\le |\sigma_j(c)|\le 4Y \]

for every \(j\).

Now take \(a\in\widetilde A_K\). Write

\[ a=uc \]

with \(u\in U_K(T)\) and \(c\in C_K\). Since

\[ e^{-T}\le |\sigma_j(u)|\le e^T, \]

we get

\[ Ye^{-T} \le |\sigma_j(a)| \le 4Ye^T. \]

But

\[ 4Ye^T = 4\cdot\frac{e^{L-T}}4\cdot e^T = e^L = X. \]

Therefore

\[ |\sigma_j(a)|\le X \]

for every \(a\in\widetilde A_K\) and every \(j\).

We will also use the lower bound

\[ |\sigma_j(a)|\ge \ell, \qquad \ell:=Ye^{-T}. \]

Since \(Y=e^{3T}/4\),

\[ \ell=\frac{e^{2T}}4. \]

6. Size of \(A_K\)

Because \(1\in U_K(T)\),

\[ C_K\subset\widetilde A_K. \]

Therefore

\[ n\ge |C_K|=|B_K(Y)|. \]

By Lemma 2.1,

\[ |B_K(Y)| \ge \frac{Y^d}{\sqrt{|\Delta_K|}}-1. \]

Since \(|\Delta_K|^{1/d}\le D\),

\[ \sqrt{|\Delta_K|}\le D^{d/2}. \]

Thus

\[ n \ge \left(\frac{Y}{\sqrt D}\right)^d-1. \]

By definition of \(\alpha\),

\[ \frac{Y}{\sqrt D} = 2e^\alpha. \]

Since \(\alpha>0\),

\[ (2e^\alpha)^d-1\ge e^{\alpha d} \]

for every \(d\ge1\). Hence

\[ n\ge e^{\alpha d}. \tag{6.1} \]

On the other hand, we proved that

\[ \widetilde A_K\subset B_K(X). \]

Therefore, by Lemma 2.1,

\[ n \le |B_K(X)| \le (2X+1)^d. \]

Since \(X\ge1\),

\[ 2X+1\le3X. \]

Hence

\[ n\le (3X)^d=e^{\beta d}. \tag{6.2} \]

7. Sumset estimate

For \(a,b\in\widetilde A_K\),

\[ |\sigma_j(a+b)| \le |\sigma_j(a)|+|\sigma_j(b)| \le 2X. \]

Thus

\[ \widetilde A_K+\widetilde A_K\subset B_K(2X). \]

By Lemma 2.1,

\[ |\widetilde A_K+\widetilde A_K| \le |B_K(2X)| \le (4X+1)^d. \]

Since \(X\ge1\),

\[ 4X+1\le5X. \]

Therefore

\[ |A_K+A_K| = |\widetilde A_K+\widetilde A_K| \le (5X)^d = e^{\beta_+d}. \]

Using \(n\ge e^{\alpha d}\), we get

\[ e^{\beta_+d} \le n^{\beta_+/\alpha}. \]

Hence

\[ |A_K+A_K| \le n^{\beta_+/\alpha} = n^{2-\delta_{\mathrm{sum}}}. \]

Since \(\delta\le\delta_{\mathrm{sum}}\),

\[ |A_K+A_K|\le n^{2-\delta}. \tag{7.1} \]

8. Product set estimate

Let

\[ U:=U_K(T). \]

Let \(\mathcal P\) be the set of principal ideals represented by elements of \(\widetilde A_K\):

\[ \mathcal P := \{(a):a\in\widetilde A_K\}. \]

8.1. Each represented ideal has many representatives

Fix \(I\in\mathcal P\). Choose \(a\in\widetilde A_K\) with

\[ I=(a). \]

Write

\[ a=uc \]

with \(u\in U\) and \(c\in C_K\). Since \(u\) is a unit,

\[ (a)=(c). \]

For every \(v\in U\),

\[ vc\in U C_K=\widetilde A_K \]

and

\[ (vc)=(c)=I. \]

The elements \(vc\) are distinct as \(v\) varies because \(c\ne0\). Therefore every ideal in \(\mathcal P\) has at least \(|U|\) representatives in \(\widetilde A_K\). Hence

\[ |\mathcal P| \le \frac{n}{|U|}. \tag{8.1} \]

8.2. Product ideals

If

\[ z=ab\in\widetilde A_K\widetilde A_K, \]

then

\[ (z)=(a)(b) \]

with \((a),(b)\in\mathcal P\). Thus the number of possible principal ideals generated by products is at most

\[ |\mathcal P|^2 \le \left(\frac{n}{|U|}\right)^2. \tag{8.2} \]

8.3. Generators per product ideal

Every \(a\in\widetilde A_K\) satisfies

\[ \ell\le|\sigma_j(a)|\le X \]

for every \(j\). Therefore every product \(z=ab\) satisfies

\[ \ell^2\le|\sigma_j(z)|\le X^2. \]

Fix a product \(z_0\in\widetilde A_K\widetilde A_K\). If another product \(z\) generates the same principal ideal, then

\[ (z)=(z_0), \]

so

\[ z=\varepsilon z_0 \]

for some unit \(\varepsilon\in\mathcal O_K^\times\).

For each embedding,

\[ |\sigma_j(\varepsilon)| = \frac{|\sigma_j(z)|}{|\sigma_j(z_0)|}. \]

Since both \(z\) and \(z_0\) have all conjugates between \(\ell^2\) and \(X^2\),

\[ \frac{\ell^2}{X^2} \le |\sigma_j(\varepsilon)| \le \frac{X^2}{\ell^2}. \]

Hence

\[ |\log|\sigma_j(\varepsilon)||\le 2\log(X/\ell). \]

Now

\[ X=e^{4T}, \qquad \ell=\frac{e^{2T}}4, \]

so

\[ \frac{X}{\ell}=4e^{2T}. \]

Thus

\[ 2\log(X/\ell)=4T+\log16. \]

Set

\[ S:=4T+\log16. \]

Then every quotient unit \(\varepsilon\) arising above lies in \(U_K(S)\). Therefore each product ideal contributes at most \(|U_K(S)|\) elements to the product set.

Combining with (8.2),

\[ |\widetilde A_K\widetilde A_K| \le \left(\frac{n}{|U_K(T)|}\right)^2 |U_K(S)|. \tag{8.3} \]

8.4. Comparing \(U_K(S)\) to \(U_K(T)\)

Since \(T\ge1\),

\[ \frac{S}{T} = 4+\frac{\log16}{T} < 7. \]

Thus

\[ 20>\frac{2S}{T}. \]

By Lemma 2.3 with \(q=20\),

\[ |U_K(S)|\le20^{d-1}|U_K(T)|\le20^d|U_K(T)|. \]

Substitute into (8.3):

\[ |\widetilde A_K\widetilde A_K| \le n^2\frac{20^d}{|U_K(T)|}. \tag{8.4} \]

8.5. Lower bound for \(|U_K(T)|\)

By Lemma 2.2,

\[ |U_K(T)| \ge \frac{(T/2)^{d-1}}{R_K}-1. \]

Since \(R_K\le E^d\),

\[ |U_K(T)| \ge \frac{(T/2)^{d-1}}{E^d}-1. \]

Recall

\[ \rho=\frac{T}{4E}. \]

Then

\[ \frac{(T/2)^{d-1}}{E^d} = \rho^d\frac{2^{d+1}}{T}. \]

Since \(d\to\infty\), for all sufficiently large \(d\),

\[ \frac{2^{d+1}}{T}\ge2. \]

Because \(\rho>20>1\), we then have

\[ \frac{(T/2)^{d-1}}{E^d}-1 \ge 2\rho^d-1 \ge \rho^d. \]

Thus, after discarding finitely many fields,

\[ |U_K(T)|\ge\rho^d. \tag{8.5} \]

Combining (8.4) and (8.5),

\[ |\widetilde A_K\widetilde A_K| \le n^2\left(\frac{20}{\rho}\right)^d. \]

Since

\[ \eta=\log\left(\frac{\rho}{20}\right)>0, \]

this is

\[ |\widetilde A_K\widetilde A_K| \le n^2e^{-\eta d}. \]

Using the upper size bound \(n\le e^{\beta d}\), we have

\[ d\ge\frac{\log n}{\beta}. \]

Therefore

\[ e^{-\eta d} \le n^{-\eta/\beta}. \]

Hence

\[ |A_KA_K| = |\widetilde A_K\widetilde A_K| \le n^{2-\eta/\beta} = n^{2-\delta_{\mathrm{prod}}}. \]

Since \(\delta\le\delta_{\mathrm{prod}}\),

\[ |A_KA_K|\le n^{2-\delta}. \tag{8.6} \]

9. Completion

Let \(K_i\) be the infinite sequence from Lemma 1.1. Discard finitely many initial fields so that the large-degree assumption used in (8.5) holds for every remaining \(K_i\). For each remaining \(K_i\), construct

\[ A_i:=A_{K_i}\subset\mathbb R \]

as above.

By (6.1),

\[ |A_i|\ge e^{\alpha d_i}. \]

Since \(d_i\to\infty\) and \(\alpha>0\),

\[ |A_i|\to\infty. \]

By (7.1) and (8.6),

\[ |A_i+A_i|\le |A_i|^{2-\delta} \]

and

\[ |A_iA_i|\le |A_i|^{2-\delta}. \]

Therefore

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

for all \(i\), with one fixed absolute constant \(\delta>0\).

This proves the theorem. \(\square\)
