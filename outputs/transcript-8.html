Below is the approach I would pursue first. It is a reduction of the theorem to a concrete arithmetic construction. The reduction is fully proved; the remaining input is a sharply stated “many bounded units” statement for real number fields. In my view this is the most promising route because it separates the two jobs:

  • an additive core \(C\), which keeps sums small;
  • a multiplicative cloud \(U\) of units, which makes products collapse because \(UU\) is much smaller than \(U^2\).

The final set is a shifted product set

\[ A=U(q+C)=\{u(q+c):u\in U,\ c\in C\}\subset \mathbb R. \]

The shift \(q\) is used only to make the pieces \(u(q+C)\) disjoint, so that \(|A|=|U||C|\).

1. Why this approach is natural

Suppose \(C\) is an additive box in a real number field \(K\), and \(U\subset K^\times\) is a finite set of units. Put \(A=U(q+C)\). Then

\[ A+A \subseteq \bigcup_{u,v\in U} \Big(q(u+v)+uC+vC\Big). \]

Thus if, for every \(u,v\in U\), the set \(uC+vC\) is only moderately larger than \(C\), then the sumset is at most about

\[ |U|^2 |C|. \]

On the other hand,

\[ AA \subseteq (UU)(q+C)(q+C), \]

so

\[ |AA|\le |UU|\, |(q+C)(q+C)|. \]

Using only the trivial bound \(|(q+C)(q+C)|\le |C|^2\), we get

\[ |AA|\le |UU|\, |C|^2. \]

Now write

\[ s=|U|,\qquad m=|C|,\qquad N=|A|=sm. \]

If \(UU\) is significantly smaller than \(U^2\), say \(|UU|\le s^{2-\eta}\), then

\[ |AA|\le s^{2-\eta}m^2=N^2 s^{-\eta}, \]

which is a power saving provided \(s\) itself is a power of \(N\). Meanwhile

\[ |A+A|\lesssim s^2m=\frac{N^2}{m}, \]

so the sumset has a power saving provided \(m\) is a power of \(N\).

Thus the construction wants:

  1. \(U\) exponentially large with \(|UU|\ll |U|^2\);
  2. \(C\) exponentially large with \(uC+vC\) not much larger than \(C\);
  3. \(U\) acts on \(C\) by genuine multiplication in a real field.

This is exactly what high-rank unit groups in totally real number fields are designed to provide.

2. Abstract unit-thickening lemma

We first prove a general lemma. This is the main reduction.

Lemma 2.1 — separating the \(U\)-dilates by a shift

Let \(K\) be a field of characteristic \(0\), let \(U\subset K^\times\) and \(C\subset K\) be finite. Then for all but finitely many integers \(q\), the map

\[ U\times C\to K,\qquad (u,c)\mapsto u(q+c) \]

is injective. Equivalently, the sets \(u(q+C)\), \(u\in U\), are pairwise disjoint.

Proof

Suppose

\[ u(q+c)=v(q+c') \]

with \(u,v\in U\) and \(c,c'\in C\).

If \(u=v\), then \(u(q+c)=u(q+c')\), hence \(c=c'\).

If \(u\ne v\), then

\[ q(u-v)=vc'-uc, \]

so

\[ q=\frac{vc'-uc}{u-v}. \]

For each quadruple \((u,v,c,c')\) with \(u\ne v\), this excludes at most one value of \(q\). There are only finitely many such quadruples. Therefore all but finitely many integers \(q\) work. \(\square\)

Proposition 2.2 — unit-thickening reduction

Let \(d_i\to\infty\) be a sequence of positive integers. Suppose that for each \(i\) we have:

  • a real number field \(K_i\subset \mathbb R\);
  • a finite set \(U_i\subset K_i^\times\);
  • a finite set \(C_i\subset K_i\);

and constants

\[ \alpha,\beta,\lambda,\phi>0 \]

such that, as \(i\to\infty\),

\[ \log |U_i|=(\alpha+o(1))d_i, \]
\[ \log |U_iU_i|\le (\beta+o(1))d_i, \]
\[ \log |C_i|=(\lambda+o(1))d_i, \]

and

\[ \max_{u,v\in U_i}|uC_i+vC_i| \le \exp\big((\lambda+\phi+o(1))d_i\big). \]

Assume moreover that

\[ \beta<2\alpha \]

and

\[ \phi<\lambda. \]

Then there is an infinite sequence of finite sets \(A_i\subset \mathbb R\) such that \(|A_i|\to\infty\) and

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

for some absolute \(\delta>0\).

More explicitly, any

\[ 0<\delta< \min\left\{ \frac{\lambda-\phi}{\alpha+\lambda}, \frac{2\alpha-\beta}{\alpha+\lambda} \right\} \]

works after discarding finitely many \(i\).

Proof

For each \(i\), choose an integer \(q_i\) such that the map

\[ U_i\times C_i\to K_i,\qquad (u,c)\mapsto u(q_i+c) \]

is injective. This is possible by Lemma 2.1.

Define

\[ A_i:=U_i(q_i+C_i) = \{u(q_i+c):u\in U_i,\ c\in C_i\}. \]

Then

\[ |A_i|=|U_i||C_i|. \]

Write

\[ s_i:=|U_i|, \qquad m_i:=|C_i|, \qquad N_i:=|A_i|=s_i m_i. \]

By hypothesis,

\[ \log N_i = (\alpha+\lambda+o(1))d_i. \]

We now bound the sumset.

For \(a=u(q_i+c)\) and \(a'=v(q_i+c')\),

\[ a+a' = q_i(u+v)+uc+vc'. \]

Thus

\[ A_i+A_i \subseteq \bigcup_{u,v\in U_i} \left(q_i(u+v)+uC_i+vC_i\right). \]

Therefore

\[ |A_i+A_i| \le \sum_{u,v\in U_i}|uC_i+vC_i| \le |U_i|^2 \max_{u,v\in U_i}|uC_i+vC_i|. \]

Using the hypotheses,

\[ \log |A_i+A_i| \le 2\log |U_i| + (\lambda+\phi+o(1))d_i = (2\alpha+\lambda+\phi+o(1))d_i. \]

Since

\[ \log N_i=(\alpha+\lambda+o(1))d_i, \]

we get

\[ \log |A_i+A_i| \le \left( 2-\frac{\lambda-\phi}{\alpha+\lambda}+o(1) \right) \log N_i. \]

Thus, for any

\[ \delta_+< \frac{\lambda-\phi}{\alpha+\lambda}, \]

we have

\[ |A_i+A_i|\le |A_i|^{2-\delta_+} \]

for all sufficiently large \(i\).

Now bound the product set. We have

\[ A_iA_i = \{uv(q_i+c)(q_i+c'):u,v\in U_i,\ c,c'\in C_i\}. \]

Hence

\[ A_iA_i \subseteq \bigcup_{w\in U_iU_i}w(q_i+C_i)(q_i+C_i). \]

For each fixed \(w\in K_i^\times\), multiplication by \(w\) is injective, so

\[ |w(q_i+C_i)(q_i+C_i)| = |(q_i+C_i)(q_i+C_i)| \le |C_i|^2. \]

Therefore

\[ |A_iA_i| \le |U_iU_i|\, |C_i|^2. \]

Using the hypotheses,

\[ \log |A_iA_i| \le (\beta+o(1))d_i + 2(\lambda+o(1))d_i = (\beta+2\lambda+o(1))d_i. \]

Since \(\log N_i=(\alpha+\lambda+o(1))d_i\),

\[ \log |A_iA_i| \le \left( 2-\frac{2\alpha-\beta}{\alpha+\lambda}+o(1) \right)\log N_i. \]

Thus, for any

\[ \delta_\times< \frac{2\alpha-\beta}{\alpha+\lambda}, \]

we have

\[ |A_iA_i|\le |A_i|^{2-\delta_\times} \]

for all sufficiently large \(i\).

Taking

\[ 0<\delta< \min\left\{ \frac{\lambda-\phi}{\alpha+\lambda}, \frac{2\alpha-\beta}{\alpha+\lambda} \right\}, \]

we obtain

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

for all sufficiently large \(i\). Since \(d_i\to\infty\) and \(\alpha+\lambda>0\), we also have \(|A_i|\to\infty\). \(\square\)

3. How to realize the hypotheses using totally real fields

The proposition reduces the problem to building \(U_i\) and \(C_i\). The natural arithmetic setting is the following.

Let \(K\) be a totally real number field of degree \(d\), with embeddings

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow \mathbb R. \]

For \(R>0\), define the Minkowski box

\[ B_K(R):= \{x\in \mathcal O_K:\ |\sigma_j(x)|\le R\text{ for every }j=1,\dots,d\}. \]

Let

\[ C=B_K(R). \]

Let \(U\subset \mathcal O_K^\times\) be a set of units whose archimedean sizes are uniformly bounded. More precisely, suppose there is some fixed \(T>0\) such that

\[ |\log |\sigma_j(u)||\le T \]

for every \(u\in U\) and every \(j\). Equivalently,

\[ e^{-T}\le |\sigma_j(u)|\le e^T \]

for every \(j\). Put

\[ H:=e^T. \]

Then for \(x,y\in C\) and \(u,v\in U\),

\[ |\sigma_j(ux+vy)| \le |\sigma_j(u)|\,|\sigma_j(x)| + |\sigma_j(v)|\,|\sigma_j(y)| \le HR+HR = 2HR. \]

Therefore

\[ uC+vC\subseteq B_K(2HR). \]

Thus

\[ |uC+vC| \le |B_K(2HR)|. \]

So the condition

\[ |uC+vC|\le \exp((\lambda+\phi+o(1))d) \]

will follow if

\[ |B_K(R)|=\exp((\lambda+o(1))d) \]

and

\[ |B_K(2HR)|=\exp((\lambda+\phi+o(1))d). \]

For a well-behaved tower of totally real fields with bounded root discriminant, one expects

\[ |B_K(R)| \approx \frac{(2R)^d}{\sqrt{|\Delta_K|}}. \]

If the root discriminant

\[ \operatorname{rd}(K)=|\Delta_K|^{1/d} \]

is bounded by some constant \(D_0\), then heuristically

\[ |B_K(R)| \approx \left(\frac{2R}{D_0^{1/2}}\right)^d. \]

Similarly,

\[ |B_K(2HR)| \approx \left(\frac{4HR}{D_0^{1/2}}\right)^d. \]

Thus

\[ \frac{|B_K(2HR)|}{|B_K(R)|} \approx (2H)^d. \]

In this regular situation, one may take

\[ \phi=\log(2H)=\log 2+T. \]

Then the condition \(\phi<\lambda\) is achieved by choosing \(R\) large enough so that \(C=B_K(R)\) has exponential size base larger than \(2H\).

So the additive-core side is plausible once the fields have reasonably regular Minkowski lattices.

4. The unit-rich input needed

The real difficulty is to construct the multiplicative cloud \(U\).

For a totally real field \(K\), define the logarithmic unit lattice

\[ \Lambda_K := \left\{ \left(\log|\sigma_1(u)|,\dots,\log|\sigma_d(u)|\right) : u\in \mathcal O_K^\times \right\}. \]

Because \(u\) is a unit,

\[ \prod_{j=1}^d |\sigma_j(u)|=1, \]

so the logarithmic vector lies in the hyperplane

\[ \mathcal H_d:=\left\{(x_1,\dots,x_d)\in\mathbb R^d:\sum_{j=1}^d x_j=0\right\}. \]

For \(T>0\), define

\[ U_K(T) := \left\{ u\in \mathcal O_K^\times: \|\ell(u)\|_\infty\le T \right\}, \]

where

\[ \ell(u) = (\log|\sigma_1(u)|,\dots,\log|\sigma_d(u)|). \]

Then

\[ U_K(T)U_K(T) \subseteq U_K(2T), \]

because logarithmic embeddings add under multiplication.

Thus, if we can find fields \(K_i\) of degree \(d_i\to\infty\) and a fixed \(T>0\) such that

\[ |U_{K_i}(T)| = \exp((\alpha+o(1))d_i) \]

and

\[ |U_{K_i}(2T)| \le \exp((\beta+o(1))d_i) \]

with

\[ \beta<2\alpha, \]

then the multiplicative hypothesis of Proposition 2.2 holds.

So the key remaining arithmetic statement is:

Main remaining arithmetic lemma

There exist constants \(T>0\), \(\alpha>0\), \(\beta<2\alpha\), and an infinite sequence of totally real number fields \(K_i\) with \([K_i:\mathbb Q]=d_i\to\infty\), such that

\[ |U_{K_i}(T)| = \exp((\alpha+o(1))d_i), \]

and

\[ |U_{K_i}(2T)| \le \exp((\beta+o(1))d_i). \]

Equivalently, the logarithmic unit lattices \(\Lambda_{K_i}\) should contain exponentially many points in a fixed cube \([-T,T]^{d_i}\), but the doubled cube \([-2T,2T]^{d_i}\) should still contain exponentially fewer than the square of that number.

5. Why this arithmetic lemma is plausible

Suppose, very heuristically, that the unit log lattice \(\Lambda_K\subset \mathcal H_d\) behaves like a reasonably well-distributed lattice of covolume

\[ \operatorname{Reg}(K)\approx e^{\rho d}. \]

Then the number of points in the cube \([-T,T]^d\cap\mathcal H_d\) should be roughly

\[ \frac{\operatorname{Vol}_{d-1}([-T,T]^d\cap\mathcal H_d)} {\operatorname{Reg}(K)} \approx \frac{(2T)^d}{e^{\rho d}} = \exp((\log(2T)-\rho)d). \]

Similarly,

\[ |U_K(2T)| \approx \exp((\log(4T)-\rho)d). \]

Thus one would have

\[ \alpha\approx \log(2T)-\rho, \]

and

\[ \beta\approx \log(4T)-\rho. \]

The inequality \(\beta<2\alpha\) becomes

\[ \log(4T)-\rho < 2\log(2T)-2\rho. \]

Equivalently,

\[ \rho<\log T. \]

Thus, if the regulator density \(\rho\) is bounded and the log-unit lattices are sufficiently well distributed, then choosing \(T>e^\rho\) should give the required multiplicative saving.

This suggests a concrete path:

  1. Find a tower of totally real fields \(K_i\) with \(d_i\to\infty\), bounded root discriminant, and regulator \(\le e^{\rho d_i+o(d_i)}\).
  2. Prove enough regularity of the unit log lattice to count points in fixed cubes.
  3. Choose \(T\) large enough that \(\beta<2\alpha\).
  4. Choose an additive core \(C_i=B_{K_i}(R)\) with \(R\) large enough that the additive expansion exponent \(\phi\) satisfies \(\phi<\lambda\).
  5. Apply Proposition 2.2.

6. A precise conditional theorem from the number-field package

Let me package the needed number-theoretic input in a form that can be attacked directly.

Theorem 6.1 — conditional number-field package implies the sum-product counterexample

Suppose there exist constants \(T,R>0\), \(\alpha,\beta,\lambda,\phi>0\), and totally real fields \(K_i\) of degrees \(d_i\to\infty\), such that with

\[ U_i:=U_{K_i}(T) = \{u\in \mathcal O_{K_i}^\times:\|\ell(u)\|_\infty\le T\}, \]

and

\[ C_i:=B_{K_i}(R) = \{x\in\mathcal O_{K_i}:|\sigma_j(x)|\le R\ \forall j\}, \]

we have

\[ \log |U_i|=(\alpha+o(1))d_i, \]
\[ \log |U_iU_i|\le(\beta+o(1))d_i, \]
\[ \log |C_i|=(\lambda+o(1))d_i, \]

and

\[ \log |B_{K_i}(2e^T R)| \le (\lambda+\phi+o(1))d_i. \]

Assume

\[ \beta<2\alpha \]

and

\[ \phi<\lambda. \]

Then the theorem follows.

Proof

For \(u,v\in U_i\), and \(x,y\in C_i\),

\[ |\sigma_j(ux+vy)| \le e^T R+e^T R = 2e^T R. \]

Thus

\[ uC_i+vC_i\subseteq B_{K_i}(2e^T R), \]

so

\[ |uC_i+vC_i| \le |B_{K_i}(2e^T R)| \le \exp((\lambda+\phi+o(1))d_i). \]

Also

\[ U_iU_i\subseteq U_{K_i}(2T), \]

so the assumed bound on \(|U_iU_i|\) holds.

Therefore all hypotheses of Proposition 2.2 are satisfied. \(\square\)

7. Parameter calculation in the regular-lattice model

To see how the constants would work in an idealized regular family, suppose:

  • the root discriminants \(\operatorname{rd}(K_i)\) tend to a finite limit \(D_0\);
  • the Minkowski lattice point count satisfies the expected estimate
\[ |B_{K_i}(R)| = \exp\left(\left(\log(2R)-\frac12\log D_0+o(1)\right)d_i\right); \]
  • the unit log lattice has regulator density \(\rho\), so
\[ |U_{K_i}(T)| = \exp((\log(2T)-\rho+o(1))d_i), \]

and

\[ |U_{K_i}(2T)| = \exp((\log(4T)-\rho+o(1))d_i). \]

Then

\[ \alpha=\log(2T)-\rho, \]
\[ \beta=\log(4T)-\rho, \]

and

\[ 2\alpha-\beta = 2(\log(2T)-\rho)-(\log(4T)-\rho) = \log T-\rho. \]

So the product-saving condition \(\beta<2\alpha\) is equivalent to

\[ T>e^\rho. \]

For the additive core,

\[ \lambda=\log(2R)-\frac12\log D_0, \]

and

\[ \lambda+\phi = \log(4e^T R)-\frac12\log D_0. \]

Hence

\[ \phi = \log(2e^T) = \log 2+T. \]

The sum-saving condition is

\[ \lambda>\phi, \]

i.e.

\[ \log(2R)-\frac12\log D_0>\log 2+T. \]

Equivalently,

\[ R>e^T D_0^{1/2}. \]

Thus, in the regular model, one may choose:

  1. \(T>e^\rho\);
  2. \(R>e^T D_0^{1/2}\).

Then Proposition 2.2 gives

\[ \delta < \min\left\{ \frac{\lambda-\phi}{\alpha+\lambda}, \frac{2\alpha-\beta}{\alpha+\lambda} \right\}. \]

Both numerator terms are positive, so \(\delta>0\).

8. Remaining gaps

The reduction above is complete. The unresolved work is to build the number-field package.

I would split the remaining work into three precise gaps.

Gap 1 — construct many bounded-height units with small doubling

Precise statement needed

Find constants \(T>0\), \(\alpha>0\), \(\beta<2\alpha\), and totally real fields \(K_i\) of degrees \(d_i\to\infty\), such that

\[ |U_{K_i}(T)| = \exp((\alpha+o(1))d_i), \]

and

\[ |U_{K_i}(2T)| \le \exp((\beta+o(1))d_i). \]

Equivalently, the logarithmic unit lattice should have exponentially many points in a fixed cube, but not so many in the doubled cube that doubling becomes quadratic.

Assessment

This is the serious obstruction in the approach. It is the arithmetic heart of the construction.

However, it is plausible because if the logarithmic unit lattice is reasonably well distributed with exponential covolume \(e^{\rho d}\), then the cube-count heuristic gives exactly what is needed. One needs either:

  1. a tower of totally real fields whose unit log lattices are sufficiently well-rounded; or
  2. an explicit family, likely cyclotomic or class-field-tower based, with many bounded-height units.

Possible concrete routes

Route A: cyclotomic real subfields

Let

\[ K_m=\mathbb Q(\zeta_m+\zeta_m^{-1}). \]

Cyclotomic units give an explicit finite-index subgroup of \(\mathcal O_{K_m}^\times\). The log embeddings of cyclotomic units are expressed through trigonometric quantities such as

\[ \log\left|\frac{\sin(\pi ak/m)}{\sin(\pi k/m)}\right|. \]

One would need to show that there are exponentially many cyclotomic units for which all these logarithms are bounded by a fixed \(T\). This becomes a Fourier/discrepancy problem: construct many integer combinations of cyclotomic units whose log vectors are uniformly bounded.

If achieved, the doubled-cube bound follows automatically from the same counting estimates.

Route B: class field towers with controlled regulator

Use a totally real class field tower with bounded root discriminant. One expects the regulator to grow at most exponentially. If one can additionally show that the unit log lattice is not too skew, then fixed log-cubes contain exponentially many units.

The key technical point is lattice regularity: small regulator alone does not guarantee many points in a fixed cube, because the lattice could be highly anisotropic. One needs either bounded covering radius after normalization or at least enough short independent directions.

Route C: explicit root-lattice-like units

A very strong sufficient condition would be to construct fields whose unit log lattices contain a sublattice comparable to a scaled \(A_{d-1}\) root lattice. Then cubes contain exponentially many lattice points and doubling the cube increases the count by only an exponential factor, not by squaring.

Concretely, one would like units whose log vectors behave like bounded multiples of \(e_i-e_j\). This would give bounded-height units with many independent choices.

Gap 2 — build additive cores with controlled expansion

Precise statement needed

For the same fields \(K_i\), find finite sets \(C_i\subset \mathcal O_{K_i}\) such that

\[ |C_i|=\exp((\lambda+o(1))d_i) \]

and

\[ \max_{u,v\in U_i}|uC_i+vC_i| \le \exp((\lambda+\phi+o(1))d_i) \]

with

\[ \phi<\lambda. \]

Assessment

This looks less serious than Gap 1. If the fields have bounded root discriminant and reasonably regular Minkowski lattices, then taking

\[ C_i=B_{K_i}(R) \]

should work.

Indeed, bounded-height units send \(B_{K_i}(R)\) into \(B_{K_i}(e^T R)\), and therefore

\[ uC_i+vC_i\subseteq B_{K_i}(2e^T R). \]

Thus it suffices to prove lattice-point estimates for \(B_{K_i}(R)\) and \(B_{K_i}(2e^T R)\). For well-rounded Minkowski lattices, these estimates are standard.

The possible issue is skewness of the lattice \(\sigma(\mathcal O_K)\). If the lattice is extremely skew, a fixed box may not contain the expected number of lattice points. This can likely be handled either by selecting a better additive generalized progression inside \(\mathcal O_K\), or by choosing fields with controlled geometry of numbers.

Gap 3 — ensure the final set has the expected size

This is already solved by Lemma 2.1. For each finite \(U_i,C_i\), choose an integer \(q_i\) avoiding finitely many bad values. Then

\[ |U_i(q_i+C_i)|=|U_i||C_i|. \]

The shift does not affect the sumset estimates, because for fixed \(u,v\),

\[ u(q+C)+v(q+C)=q(u+v)+uC+vC, \]

and translation does not change cardinality. It also does not harm the product estimate, because we use only

\[ |(q+C)(q+C)|\le |C|^2. \]

So this part is complete.

10. Summary of the proof plan

The proposed construction is:

  1. Choose a totally real number field \(K_i\) of large degree \(d_i\).

  2. Let \(U_i\) be the set of units with bounded logarithmic embeddings:

    \[ U_i=\{u\in\mathcal O_{K_i}^\times:\|\ell(u)\|_\infty\le T\}. \]

  3. Let \(C_i\) be an additive core, ideally a Minkowski box:

    \[ C_i=\{x\in\mathcal O_{K_i}:|\sigma_j(x)|\le R\ \forall j\}. \]
  4. Choose an integer shift \(q_i\) such that the sets \(u(q_i+C_i)\) are disjoint.

  5. Define

    \[ A_i=U_i(q_i+C_i)\subset K_i\subset\mathbb R. \]

  6. Then

    \[ |A_i|=|U_i||C_i|. \]

  7. The sumset satisfies

    \[ |A_i+A_i| \le |U_i|^2\max_{u,v\in U_i}|uC_i+vC_i|. \]

  8. The product set satisfies

    \[ |A_iA_i| \le |U_iU_i|\, |C_i|^2. \]

  9. If

    \[ |U_i|=\exp((\alpha+o(1))d_i), \]
    \[ |U_iU_i|\le \exp((\beta+o(1))d_i), \]
    \[ |C_i|=\exp((\lambda+o(1))d_i), \]

    and

    \[ \max_{u,v}|uC_i+vC_i| \le \exp((\lambda+\phi+o(1))d_i), \]

    \[ \beta<2\alpha, \qquad \phi<\lambda, \]

    \[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

    for every

    \[ 0<\delta< \min\left\{ \frac{\lambda-\phi}{\alpha+\lambda}, \frac{2\alpha-\beta}{\alpha+\lambda} \right\}. \]

Thus the theorem is reduced to constructing a tower of totally real fields with exponentially many bounded-height units whose bounded-height doubling is exponentially smaller than quadratic.

Below is a complete proof following the “unit-thickening” strategy, but with one important strengthening of the first-round plan:

Instead of needing a highly regular unit lattice, we use only a bounded-regulator totally real class-field tower and a Blichfeldt difference argument. This gives exponentially many bounded units in a fixed logarithmic box, with small multiplicative doubling.

The proof uses three standard external inputs:

  1. the Golod–Shafarevich–Martinet theorem that there exist infinite totally real class-field towers, hence totally real fields of unbounded degree and bounded root discriminant;
  2. Landau’s standard residue bound for Dedekind zeta functions, used only to deduce that such fields have regulators at most exponential in the degree;
  3. Vaaler’s cube-section theorem, used only to lower-bound the volume of a central section of a cube.

Everything else is elementary.

1. Lattice-counting lemmas

We begin with two elementary geometry-of-numbers facts.

Lemma 1.1 — Blichfeldt difference lower bound

Let \(\Lambda\) be a lattice in an \(n\)-dimensional real vector space \(V\), and let \(B\subset V\) be a bounded measurable centrally symmetric set. Then

\[ |\Lambda\cap (B-B)| \ge \frac{\operatorname{vol}(B)}{\det \Lambda}. \]

In particular, if \(B\) is centrally symmetric, then \(B-B=2B\), so

\[ |\Lambda\cap 2B| \ge \frac{\operatorname{vol}(B)}{\det \Lambda}. \]

Proof

Let \(P\) be a fundamental parallelepiped for \(\Lambda\). Averaging over \(x\in P\),

\[ \frac1{\det\Lambda} \int_P |(x+B)\cap \Lambda|\,dx = \frac{\operatorname{vol}(B)}{\det\Lambda}. \]

Thus some translate \(x+B\) contains at least \(\operatorname{vol}(B)/\det\Lambda\) lattice points.

Choose one of them, say \(\lambda_0\). If \(\lambda\in (x+B)\cap\Lambda\), then

\[ \lambda-\lambda_0\in B-B. \]

The differences \(\lambda-\lambda_0\) are distinct lattice points, so

\[ |\Lambda\cap(B-B)| \ge |(x+B)\cap\Lambda| \ge \frac{\operatorname{vol}(B)}{\det\Lambda}. \]

\(\square\)

Lemma 1.2 — lattice points in dilates grow at most exponentially in dimension

Let \(\Lambda\) be a lattice in an \(n\)-dimensional real vector space \(V\), and let \(B\subset V\) be a centrally symmetric convex body. For every \(t\ge 1\),

\[ |\Lambda\cap tB| \le (2t+1)^n |\Lambda\cap B|. \]

Proof

Let \(X\subseteq \Lambda\cap tB\) be maximal with the property that for distinct \(x,x'\in X\),

\[ x-x'\notin B. \]

Then the translates

\[ x+\frac12 B,\qquad x\in X, \]

are pairwise interior-disjoint. They are all contained in

\[ tB+\frac12B=\left(t+\frac12\right)B. \]

Therefore

\[ |X|\operatorname{vol}\left(\frac12B\right) \le \operatorname{vol}\left(\left(t+\frac12\right)B\right), \]

so

\[ |X| \le \left(\frac{t+\frac12}{\frac12}\right)^n = (2t+1)^n. \]

By maximality of \(X\), every \(y\in\Lambda\cap tB\) satisfies \(y-x\in B\) for some \(x\in X\). Hence

\[ \Lambda\cap tB \subseteq X+(\Lambda\cap B). \]

Thus

\[ |\Lambda\cap tB| \le |X|\,|\Lambda\cap B| \le (2t+1)^n|\Lambda\cap B|. \]

\(\square\)

2. Arithmetic input: totally real fields with bounded root discriminant and exponential regulator

We need a sequence of totally real fields of increasing degree whose root discriminants are bounded and whose regulators are at most exponential in the degree.

Proposition 2.1 — field tower with controlled unit-lattice covolume

There exist constants \(D\ge 1\), \(F\ge 1\), and an infinite sequence of totally real number fields

\[ K_i \]

with degrees

\[ d_i=[K_i:\mathbb Q]\to\infty \]

such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

and such that the logarithmic unit lattice of \(K_i\) has Euclidean covolume at most

\[ F^{d_i}. \]

More precisely, if

\[ \ell_i:\mathcal O_{K_i}^{\times}\to \mathbb R^{d_i} \]

is the logarithmic embedding

\[ \ell_i(u) = \bigl(\log|\sigma_1(u)|,\dots,\log|\sigma_{d_i}(u)|\bigr), \]

then

\[ \Lambda_i:=\ell_i(\mathcal O_{K_i}^{\times}) \]

is a lattice in

\[ H_i:= \left\{x\in\mathbb R^{d_i}:\sum_{j=1}^{d_i}x_j=0\right\}, \]

and

\[ \det(\Lambda_i)\le F^{d_i}. \]

Proof

By the Golod–Shafarevich–Martinet theorem, there exists a totally real number field \(K_0\) with an infinite narrow Hilbert class-field tower. Taking finite layers of this tower gives totally real fields \(K_i\) of degrees \(d_i\to\infty\), unramified at all finite places over \(K_0\), with all real places splitting.

Because the extensions are unramified at finite places,

\[ \operatorname{rd}(K_i) = |\Delta_{K_i}|^{1/d_i} = |\Delta_{K_0}|^{1/[K_0:\mathbb Q]}. \]

Thus there is a constant \(D\) such that

\[ |\Delta_{K_i}|^{1/d_i}\le D \]

for all \(i\).

It remains to control the regulator. Let \(K\) be one of these totally real fields, of degree \(d\), discriminant \(\Delta_K\), class number \(h_K\), regulator \(\operatorname{Reg}_K\), and Dedekind zeta residue

\[ \kappa_K:=\operatorname*{Res}_{s=1}\zeta_K(s). \]

For totally real \(K\), the analytic class number formula gives

\[ \kappa_K = \frac{2^d h_K\operatorname{Reg}_K}{w_K\sqrt{|\Delta_K|}}, \]

where \(w_K=2\) is the number of roots of unity in \(K\). Hence

\[ h_K\operatorname{Reg}_K = 2^{1-d}\sqrt{|\Delta_K|}\,\kappa_K. \]

Since \(h_K\ge 1\),

\[ \operatorname{Reg}_K \le h_K\operatorname{Reg}_K \le \sqrt{|\Delta_K|}\,\kappa_K. \]

We now use Landau’s standard residue bound: for every number field \(K\) of degree \(d\ge 2\),

\[ \kappa_K \le \left( \frac{e\log|\Delta_K|}{2(d-1)} \right)^{d-1}, \]

after increasing the implicit absolute constant to handle the finitely many small discriminants. Since \(|\Delta_K|^{1/d}\le D\), we have

\[ \log|\Delta_K|\le d\log D. \]

Therefore

\[ \kappa_K\le C_D^d \]

for some constant \(C_D\) depending only on \(D\). Hence

\[ \operatorname{Reg}_K \le D^{d/2}C_D^d = E^d \]

for some constant \(E\ge 1\) depending only on the chosen tower.

Finally, the Euclidean covolume of the logarithmic unit lattice

\[ \Lambda_K=\ell(\mathcal O_K^\times)\subset H_d \]

is

\[ \sqrt d\,\operatorname{Reg}_K. \]

Thus, after increasing \(E\) if necessary,

\[ \det(\Lambda_K) \le \sqrt d\,E^d \le (2E)^d \]

for all \(d\ge 2\). Put \(F=2E\). This proves the proposition. \(\square\)

3. Counting bounded units

Fix once and for all a sequence \(K_i\) from Proposition 2.1.

For a totally real field \(K_i\) of degree \(d_i\), write

\[ H_i = \left\{ x\in\mathbb R^{d_i}:\sum_{j=1}^{d_i}x_j=0 \right\}. \]

We will use the cube-section theorem of Vaaler:

Vaaler’s cube-section theorem. If \(H\subset\mathbb R^d\) is a \(k\)-dimensional linear subspace, then

\[ \operatorname{vol}_k\left(H\cap[-1/2,1/2]^d\right)\ge 1. \]

In particular, for

\[ H_d=\left\{x\in\mathbb R^d:\sum_jx_j=0\right\}, \]

we have

\[ \operatorname{vol}_{d-1}\left(H_d\cap[-T/2,T/2]^d\right)\ge T^{d-1}. \]

Let \(F\) be the constant from Proposition 2.1. Choose a real number \(S>1\), very large, such that

\[ \alpha:=\frac12\log\left(\frac{S}{F}\right)>\log 10. \]

This is possible because \(F\) is fixed.

For each \(i\), define

\[ \Lambda_i:=\ell_i(\mathcal O_{K_i}^{\times}) \subset H_i. \]

Let

\[ V_i := \Lambda_i\cap[-S,S]^{d_i}. \]

By Lemma 1.1 applied in \(H_i\) to the body

\[ B_i:=H_i\cap[-S/2,S/2]^{d_i}, \]

we get

\[ |V_i| = |\Lambda_i\cap 2B_i| \ge \frac{\operatorname{vol}_{d_i-1}(B_i)}{\det\Lambda_i} \ge \frac{S^{d_i-1}}{F^{d_i}}. \]

Thus

\[ \log|V_i| \ge d_i\log(S/F)-\log S. \]

Since \(\alpha=\frac12\log(S/F)\), after discarding finitely many \(i\), we have

\[ \log|V_i|\ge \alpha d_i. \]

For every \(\lambda\in V_i\), choose one unit \(u_\lambda\in\mathcal O_{K_i}^{\times}\) with

\[ \ell_i(u_\lambda)=\lambda. \]

Define

\[ U_i:=\{u_\lambda:\lambda\in V_i\}. \]

Then

\[ |U_i|=|V_i|. \]

Put

\[ a_i:=\log|U_i|. \]

Thus, for all sufficiently large \(i\),

\[ a_i\ge \alpha d_i. \]

We also need a small-doubling estimate for \(U_i\). If \(u_\lambda,u_\mu\in U_i\), then

\[ \ell_i(u_\lambda u_\mu)=\lambda+\mu\in [-2S,2S]^{d_i}\cap H_i. \]

For a fixed logarithmic vector \(\nu\in\Lambda_i\), there are at most two units with logarithmic vector \(\nu\), because two such units differ by a unit all of whose conjugates have absolute value \(1\), hence by Kronecker’s theorem differ by a root of unity, and in a totally real field the only roots of unity are \(\pm1\).

Therefore

\[ |U_iU_i| \le 2\,|\Lambda_i\cap[-2S,2S]^{d_i}|. \]

By Lemma 1.2 in the \((d_i-1)\)-dimensional space \(H_i\), with \(t=2\),

\[ |\Lambda_i\cap[-2S,2S]^{d_i}| \le 5^{d_i-1}|\Lambda_i\cap[-S,S]^{d_i}| = 5^{d_i-1}|U_i|. \]

Hence

\[ |U_iU_i| \le 2\cdot 5^{d_i-1}|U_i| \le 10^{d_i}|U_i|. \]

Equivalently,

\[ \log|U_iU_i| \le a_i+(\log 10)d_i. \]

Let

\[ P:=\log 10. \]

Then

\[ \log|U_iU_i|\le a_i+P d_i. \]

4. Additive boxes in the same fields

For a totally real field \(K_i\), write

\[ \sigma_i(x) = (\sigma_1(x),\dots,\sigma_{d_i}(x)) \in\mathbb R^{d_i}. \]

For \(R>0\), define

\[ C_i(R) := \left\{ x\in\mathcal O_{K_i}: |\sigma_j(x)|\le R\text{ for every }j \right\}. \]

The lattice \(\sigma_i(\mathcal O_{K_i})\subset\mathbb R^{d_i}\) has covolume

\[ \sqrt{|\Delta_{K_i}|}. \]

Since

\[ |\Delta_{K_i}|^{1/d_i}\le D, \]

we have

\[ \sqrt{|\Delta_{K_i}|}\le D^{d_i/2}. \]

We need two basic estimates for \(C_i(R)\).

Lemma 4.1 — lower and upper bounds for \(C_i(R)\)

For every \(R\ge 1\),

\[ |C_i(R)| \ge \frac{R^{d_i}}{\sqrt{|\Delta_{K_i}|}} \ge R^{d_i}D^{-d_i/2}, \]

and

\[ |C_i(R)|\le (5R)^{d_i}. \]

Proof

For the lower bound, apply Lemma 1.1 to the lattice

\[ \sigma_i(\mathcal O_{K_i})\subset\mathbb R^{d_i} \]

and the cube

\[ [-R/2,R/2]^{d_i}. \]

Its difference body is \([-R,R]^{d_i}\). Hence

\[ |C_i(R)| = |\sigma_i(\mathcal O_{K_i})\cap[-R,R]^{d_i}| \ge \frac{R^{d_i}}{\sqrt{|\Delta_{K_i}|}}. \]

For the upper bound, partition \([-R,R]^{d_i}\) into half-open cubes of side length \(1/2\). Since \(R\ge1\), this requires at most \((5R)^{d_i}\) small cubes.

We claim each such small cube contains at most one point of \(\sigma_i(\mathcal O_{K_i})\). Indeed, if \(x\ne y\in\mathcal O_{K_i}\) lie in the same small cube, then for \(z=x-y\ne0\),

\[ |\sigma_j(z)|<\frac12 \]

for all \(j\). Therefore

\[ |N_{K_i/\mathbb Q}(z)| = \prod_{j=1}^{d_i}|\sigma_j(z)| < 2^{-d_i}<1. \]

But \(z\in\mathcal O_{K_i}\setminus\{0\}\), so \(N_{K_i/\mathbb Q}(z)\) is a nonzero integer, contradiction. Thus each small cube contains at most one lattice point, giving

\[ |C_i(R)|\le(5R)^{d_i}. \]

\(\square\)

We will also need a dilation estimate.

Lemma 4.2 — additive boxes have controlled dilation

For every \(L\ge1\) and \(R\ge1\),

\[ |C_i(LR)| \le (2L+1)^{d_i}|C_i(R)|. \]

Proof

Apply Lemma 1.2 to the lattice \(\sigma_i(\mathcal O_{K_i})\subset\mathbb R^{d_i}\) and the cube \([-R,R]^{d_i}\). Since

\[ [-LR,LR]^{d_i} = L[-R,R]^{d_i}, \]

we get

\[ |C_i(LR)| \le (2L+1)^{d_i}|C_i(R)|. \]

\(\square\)

Recall that \(S\) has been fixed, and every \(u\in U_i\) satisfies

\[ |\sigma_j(u)|\le e^S \]

for every embedding \(\sigma_j\).

Define

\[ \Theta:=\log(4e^S+1). \]

We will choose \(C_i\) so that its size is comparable to \(|U_i|\) but larger by a factor that compensates for the additive expansion by \(e^S\).

Set

\[ M:=\Theta+\frac12\log D+1. \]

For each sufficiently large \(i\), define

\[ R_i:=\exp\left(\frac{a_i}{d_i}+M\right), \]

and put

\[ C_i:=C_i(R_i). \]

Let

\[ c_i:=\log|C_i|. \]

By Lemma 4.1,

\[ |C_i| \ge R_i^{d_i}D^{-d_i/2} = \exp\left(a_i+Md_i-\frac12(\log D)d_i\right). \]

Since

\[ M-\frac12\log D = \Theta+1, \]

we get

\[ c_i \ge a_i+(\Theta+1)d_i. \]

Also by Lemma 4.1,

\[ |C_i| \le (5R_i)^{d_i} = \exp\left(a_i+(M+\log5)d_i\right). \]

Define

\[ B:=M+\log5. \]

Then

\[ c_i\le a_i+B d_i. \]

Thus we have, for every sufficiently large \(i\),

\[ a_i\ge \alpha d_i, \]
\[ a_i+(\Theta+1)d_i \le c_i \le a_i+B d_i. \]

6. The final set and the separating shift

We need a harmless shift to ensure that

\[ |U_i(q_i+C_i)|=|U_i||C_i|. \]

We use the following elementary lemma.

Lemma 6.1 — finite shift separation

Let \(K\) be a field of characteristic \(0\), let \(U\subset K^\times\) and \(C\subset K\) be finite. Then all but finitely many integers \(q\) have the property that the map

\[ U\times C\to K, \qquad (u,c)\mapsto u(q+c), \]

is injective.

Proof

Suppose

\[ u(q+c)=v(q+c') \]

with \(u,v\in U\) and \(c,c'\in C\).

If \(u=v\), then \(c=c'\).

If \(u\ne v\), then

\[ q(u-v)=vc'-uc, \]

so

\[ q=\frac{vc'-uc}{u-v}. \]

For each quadruple \((u,v,c,c')\) with \(u\ne v\), this excludes at most one value of \(q\). There are only finitely many such quadruples. Therefore all but finitely many integers \(q\) work. \(\square\)

For each large \(i\), choose an integer \(q_i\) satisfying Lemma 6.1 for \(U_i,C_i\).

Define

\[ E_i:=U_i(q_i+C_i)\subset K_i. \]

Then

\[ |E_i|=|U_i||C_i|. \]

Finally, choose one real embedding \(\sigma_1:K_i\hookrightarrow\mathbb R\), and define

\[ A_i:=\sigma_1(E_i)\subset\mathbb R. \]

Since \(\sigma_1\) is injective, cardinalities of sumsets and product sets are preserved under \(\sigma_1\). Thus it suffices to prove the desired bounds for \(E_i\subset K_i\).

Let

\[ N_i:=|E_i|. \]

Then

\[ \log N_i=a_i+c_i. \]

For readability, in the rest of the proof fix \(i\) and write

\[ d=d_i,\qquad a=a_i,\qquad c=c_i,\qquad N=N_i. \]

So

\[ \log N=a+c. \]

7. Sumset estimate

Take two elements of \(E_i\):

\[ u(q_i+x),\qquad v(q_i+y), \]

with \(u,v\in U_i\) and \(x,y\in C_i\). Their sum is

\[ u(q_i+x)+v(q_i+y) = q_i(u+v)+ux+vy. \]

Thus

\[ E_i+E_i \subseteq \bigcup_{u,v\in U_i} \left( q_i(u+v)+uC_i+vC_i \right). \]

Therefore

\[ |E_i+E_i| \le |U_i|^2 \max_{u,v\in U_i}|uC_i+vC_i|. \]

Now fix \(u,v\in U_i\). Since \(\ell_i(u),\ell_i(v)\in[-S,S]^d\),

\[ |\sigma_j(u)|\le e^S,\qquad |\sigma_j(v)|\le e^S \]

for every \(j\). If \(x,y\in C_i=C_i(R_i)\), then

\[ |\sigma_j(ux+vy)| \le |\sigma_j(u)|\,|\sigma_j(x)| + |\sigma_j(v)|\,|\sigma_j(y)| \le 2e^S R_i. \]

Hence

\[ uC_i+vC_i \subseteq C_i(2e^S R_i). \]

By Lemma 4.2 with

\[ L=2e^S, \]

we get

\[ |C_i(2e^S R_i)| \le (4e^S+1)^d |C_i| = e^{\Theta d}|C_i|. \]

Therefore

\[ |E_i+E_i| \le |U_i|^2 e^{\Theta d}|C_i|. \]

Taking logs,

\[ \log|E_i+E_i| \le 2a+c+\Theta d. \]

Since

\[ \log N=a+c, \]

we can rewrite this as

\[ \log|E_i+E_i| \le 2\log N-(c-\Theta d). \]

But from the construction of \(C_i\),

\[ c\ge a+(\Theta+1)d. \]

Thus

\[ c-\Theta d\ge a+d. \]

Also

\[ c\le a+Bd, \]

so

\[ \log N=a+c\le 2a+Bd. \]

Since \(a\ge \alpha d\), write \(x=a/d\ge\alpha\). Then

\[ \frac{a+d}{2a+Bd} = \frac{x+1}{2x+B}. \]

Because \(B>2\), the function

\[ x\mapsto \frac{x+1}{2x+B} \]

is increasing for \(x\ge0\). Hence

\[ \frac{a+d}{2a+Bd} \ge \frac{\alpha+1}{2\alpha+B}. \]

Therefore

\[ c-\Theta d \ge \frac{\alpha+1}{2\alpha+B}\log N. \]

So

\[ \log|E_i+E_i| \le \left( 2-\frac{\alpha+1}{2\alpha+B} \right)\log N. \]

8. Product set estimate

We have

\[ E_iE_i \subseteq (U_iU_i)(q_i+C_i)(q_i+C_i). \]

Therefore

\[ |E_iE_i| \le |U_iU_i|\, |(q_i+C_i)(q_i+C_i)|. \]

The trivial bound gives

\[ |(q_i+C_i)(q_i+C_i)|\le |C_i|^2. \]

Also we proved

\[ |U_iU_i|\le 10^d|U_i|. \]

Thus

\[ |E_iE_i| \le 10^d|U_i||C_i|^2. \]

Taking logarithms,

\[ \log|E_iE_i| \le Pd+a+2c, \]

where \(P=\log10\). Since

\[ \log N=a+c, \]

this becomes

\[ \log|E_iE_i| \le 2\log N-(a-Pd). \]

Because

\[ a\ge \alpha d \]

and

\[ \alpha>P, \]

we have \(a-Pd>0\). Again using

\[ \log N=a+c\le 2a+Bd, \]

we get

\[ \frac{a-Pd}{\log N} \ge \frac{a-Pd}{2a+Bd}. \]

Writing \(x=a/d\ge\alpha\),

\[ \frac{a-Pd}{2a+Bd} = \frac{x-P}{2x+B}. \]

The function

\[ x\mapsto \frac{x-P}{2x+B} \]

is increasing for \(x\ge P\), because its derivative is

\[ \frac{B+2P}{(2x+B)^2}>0. \]

Therefore

\[ \frac{a-Pd}{2a+Bd} \ge \frac{\alpha-P}{2\alpha+B}. \]

Hence

\[ a-Pd \ge \frac{\alpha-P}{2\alpha+B}\log N. \]

So

\[ \log|E_iE_i| \le \left( 2-\frac{\alpha-P}{2\alpha+B} \right)\log N. \]

9. Choosing a fixed \(\delta>0\)

Recall

\[ P=\log10, \]

and we chose \(S\) so that

\[ \alpha=\frac12\log(S/F)>P. \]

Thus

\[ \frac{\alpha-P}{2\alpha+B}>0. \]

Define

\[ \delta := \frac12 \min\left\{ \frac{\alpha+1}{2\alpha+B}, \frac{\alpha-P}{2\alpha+B} \right\}. \]

This is a positive absolute constant. It depends only on the fixed tower and on the fixed choice of \(S\), not on \(i\).

The estimates from Sections 7 and 8 imply that, for all sufficiently large \(i\),

\[ |E_i+E_i| \le |E_i|^{2-\delta} \]

and

\[ |E_iE_i| \le |E_i|^{2-\delta}. \]

Since \(\sigma_1:K_i\hookrightarrow\mathbb R\) is injective,

\[ |A_i+A_i| = |E_i+E_i|, \qquad |A_iA_i| = |E_iE_i|, \]

and

\[ |A_i|=|E_i|. \]

Therefore

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta}. \]

Finally,

\[ \log|A_i| = a_i+c_i \ge 2a_i+(\Theta+1)d_i \ge (2\alpha+\Theta+1)d_i, \]

and \(d_i\to\infty\). Hence

\[ |A_i|\to\infty. \]

After discarding finitely many initial terms and reindexing, we obtain an infinite sequence \(\{A_i\}\) of finite subsets of \(\mathbb R\) with \(|A_i|\to\infty\) and

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

for all \(i\).

This proves the theorem. \(\square\)

10. Summary of the construction

The final sets have the form

\[ A_i=\sigma_1\bigl(U_i(q_i+C_i)\bigr)\subset\mathbb R, \]

where:

  • \(K_i\) is a totally real field from a bounded-root-discriminant class-field tower;
  • \(U_i\) is a large finite set of units whose logarithmic embeddings lie in a fixed cube \([-S,S]^{d_i}\);
  • \(C_i\) is an additive box of algebraic integers with embeddings bounded by \(R_i\);
  • the shift \(q_i\in\mathbb Z\) ensures \(|U_i(q_i+C_i)|=|U_i||C_i|\).

The core estimates are:

\[ |U_iU_i|\le 10^{d_i}|U_i|, \]
\[ |uC_i+vC_i|\le e^{\Theta d_i}|C_i| \qquad(u,v\in U_i), \]

and

\[ |C_i|\asymp_{\exp(O(d_i))} |U_i|e^{\Theta d_i}. \]

Thus both sumset and product set lose essentially one factor of \(|U_i|\) compared with the trivial quadratic bound. Since \(|U_i|\) is exponentially large in \(d_i\), this produces a fixed power saving.

Critical audit of the previous proof

The general strategy was sound, but several points needed to be made precise.

  1. Totally real bounded-root-discriminant fields. One must explicitly use a theorem of Martinet/Golod–Shafarevich giving infinitely many totally real fields of unbounded degree and bounded root discriminant. Ordinary Hilbert class-field towers are not automatically totally real unless infinite places are controlled.

  2. Regulator bound. Bounded root discriminant does not by itself visibly imply a bounded-covolume unit lattice. We need to use the analytic class number formula plus Landau’s residue bound for Dedekind zeta functions to prove that the logarithmic unit lattice has covolume at most \(F^d\).

  3. No regularity assumption on lattices. The first plan invoked a “regular lattice” heuristic. The repaired proof avoids this: Blichfeldt’s theorem gives many lattice points in a fixed log cube from covolume alone, and a packing lemma gives the small-doubling estimate.

  4. Kernel of the log map. The logarithmic embedding identifies \(u\) and \(-u\). This introduces at most a factor \(2\), which must be included in the bound for \(|UU|\).

  5. Parameter bookkeeping. Instead of relying on asymptotic constants for \(|U_i|\) and \(|C_i|\), we choose the additive box size depending on the actual value of \(|U_i|\). This removes possible hidden assumptions.

With these repairs, the proof is rigorous.

for some absolute constant \(D\).

Classical input 2: Landau residue bound

There is an absolute constant \(C_L\) such that for every number field \(K\) of degree \(d\ge 2\),

\[ \operatorname*{Res}_{s=1}\zeta_K(s) \le \left(C_L\max\left\{1,\frac{\log|\Delta_K|}{d}\right\}\right)^d . \]

Classical input 3: Vaaler’s cube-section theorem

If \(H\subset\mathbb R^d\) is a \(k\)-dimensional linear subspace, then

\[ \operatorname{vol}_k\bigl(H\cap[-1/2,1/2]^d\bigr)\ge 1. \]

In particular, for

\[ H_d=\left\{x\in\mathbb R^d:\sum_{j=1}^d x_j=0\right\}, \]

we have

\[ \operatorname{vol}_{d-1}\bigl(H_d\cap[-S/2,S/2]^d\bigr)\ge S^{d-1}. \]

1. Logarithmic unit lattices have exponentially bounded covolume

Fix the fields \(K_i\) from Martinet’s theorem. For each \(K_i\), let

\[ \sigma_{i,1},\dots,\sigma_{i,d_i}:K_i\hookrightarrow\mathbb R \]

be its real embeddings, and define the logarithmic embedding

\[ \ell_i:\mathcal O_{K_i}^{\times}\to\mathbb R^{d_i} \]

by

\[ \ell_i(u) = \bigl(\log|\sigma_{i,1}(u)|,\dots,\log|\sigma_{i,d_i}(u)|\bigr). \]

Since \(u\) is a unit,

\[ \sum_{j=1}^{d_i}\log|\sigma_{i,j}(u)| = \log|N_{K_i/\mathbb Q}(u)| = 0. \]

Thus \(\ell_i(\mathcal O_{K_i}^{\times})\) lies in

\[ H_i= \left\{x\in\mathbb R^{d_i}:\sum_{j=1}^{d_i}x_j=0\right\}. \]

By Dirichlet’s unit theorem,

\[ \Lambda_i:=\ell_i(\mathcal O_{K_i}^{\times}) \]

is a lattice in \(H_i\) of rank \(d_i-1\).

We claim that there is a constant \(F\ge 1\) such that

\[ \det(\Lambda_i)\le F^{d_i} \]

for all \(i\).

Indeed, let \(\operatorname{Reg}_{K_i}\) be the usual regulator. The Euclidean covolume of the full logarithmic unit lattice in \(H_i\) is

\[ \det(\Lambda_i)=\sqrt{d_i}\operatorname{Reg}_{K_i}. \]

The analytic class number formula for totally real fields gives

\[ \operatorname*{Res}_{s=1}\zeta_{K_i}(s) = \frac{2^{d_i}h_{K_i}\operatorname{Reg}_{K_i}}{2\sqrt{|\Delta_{K_i}|}} = \frac{2^{d_i-1}h_{K_i}\operatorname{Reg}_{K_i}}{\sqrt{|\Delta_{K_i}|}}. \]

Hence

\[ \operatorname{Reg}_{K_i} \le h_{K_i}\operatorname{Reg}_{K_i} = 2^{1-d_i}\sqrt{|\Delta_{K_i}|}\operatorname*{Res}_{s=1}\zeta_{K_i}(s) \le \sqrt{|\Delta_{K_i}|}\operatorname*{Res}_{s=1}\zeta_{K_i}(s). \]

Since \(|\Delta_{K_i}|^{1/d_i}\le D\), Landau’s bound implies

\[ \operatorname*{Res}_{s=1}\zeta_{K_i}(s)\le L^ {d_i} \]

for some constant \(L\) depending only on \(D\). Therefore

\[ \operatorname{Reg}_{K_i}\le D^{d_i/2}L^{d_i}. \]

Since \(\sqrt{d_i}\le 2^{d_i}\), after increasing the constant if necessary we get

\[ \det(\Lambda_i) = \sqrt{d_i}\operatorname{Reg}_{K_i} \le F^{d_i}. \]

2. Two elementary lattice lemmas

We will use the following standard consequences of Blichfeldt’s principle.

Lemma 2.1: difference-body lower bound

Let \(\Lambda\) be a lattice in an \(n\)-dimensional Euclidean space \(V\), and let \(B\subset V\) be bounded, measurable, and centrally symmetric. Then

\[ |\Lambda\cap 2B| \ge \frac{\operatorname{vol}(B)}{\det\Lambda}. \]

Proof

Let \(P\) be a fundamental parallelepiped for \(\Lambda\). Averaging over \(x\in P\),

\[ \frac{1}{\det\Lambda}\int_P |(x+B)\cap\Lambda|\,dx = \frac{\operatorname{vol}(B)}{\det\Lambda}. \]

So some translate \(x+B\) contains at least \(\operatorname{vol}(B)/\det\Lambda\) lattice points. Subtract one of them from all the others. The resulting differences are distinct lattice points lying in \(B-B=2B\). Thus

\[ |\Lambda\cap 2B| \ge \frac{\operatorname{vol}(B)}{\det\Lambda}. \]

\(\square\)

Lemma 2.2: dilation upper bound

Let \(\Lambda\) be a lattice in an \(n\)-dimensional Euclidean space \(V\), and let \(B\subset V\) be a centrally symmetric convex body. For every \(t\ge 1\),

\[ |\Lambda\cap tB| \le (2t+1)^n|\Lambda\cap B|. \]

Proof

Choose \(X\subseteq\Lambda\cap tB\) maximal such that for distinct \(x,x'\in X\),

\[ x-x'\notin B. \]

Then the translates \(x+\frac12B\), \(x\in X\), are pairwise disjoint and all lie inside \((t+\frac12)B\). Therefore

\[ |X|\operatorname{vol}\left(\frac12B\right) \le \operatorname{vol}\left(\left(t+\frac12\right)B\right), \]

so

\[ |X|\le (2t+1)^n. \]

By maximality, every element of \(\Lambda\cap tB\) differs by an element of \(\Lambda\cap B\) from some element of \(X\). Hence

\[ |\Lambda\cap tB| \le |X|\,|\Lambda\cap B| \le (2t+1)^n|\Lambda\cap B|. \]

\(\square\)

3. Construction of many bounded units with small doubling

Choose a real number \(S>0\) so large that

\[ \alpha:=\frac12\log(S/F)>\log 10. \]

For each \(i\), define

\[ Q_i(S):=H_i\cap[-S,S]^{d_i}, \]

and put

\[ V_i:=\Lambda_i\cap Q_i(S). \]

By Vaaler’s theorem,

\[ \operatorname{vol}_{d_i-1}\left(H_i\cap[-S/2,S/2]^{d_i}\right) \ge S^{d_i-1}. \]

Applying Lemma 2.1 to

\[ B_i:=H_i\cap[-S/2,S/2]^{d_i}, \]

we get

\[ |V_i| = |\Lambda_i\cap Q_i(S)| \ge \frac{S^{d_i-1}}{\det\Lambda_i} \ge \frac{S^{d_i-1}}{F^{d_i}}. \]

Thus

\[ \log |V_i| \ge d_i\log(S/F)-\log S. \]

After discarding finitely many \(i\), we have

\[ \log|V_i|\ge \alpha d_i. \]

For each \(\lambda\in V_i\), choose one unit \(u_\lambda\in\mathcal O_{K_i}^{\times}\) satisfying

\[ \ell_i(u_\lambda)=\lambda. \]

Define

\[ U_i:=\{u_\lambda:\lambda\in V_i\}. \]

Then

\[ |U_i|=|V_i|. \]

Set

\[ a_i:=\log |U_i|. \]

So for all remaining \(i\),

\[ a_i\ge \alpha d_i. \]

Now we prove small multiplicative doubling. Since \(U_i\) consists of units whose logarithmic vectors lie in \(Q_i(S)\),

\[ \ell_i(U_iU_i)\subseteq \Lambda_i\cap Q_i(2S). \]

The kernel of \(\ell_i\) on \(\mathcal O_{K_i}^{\times}\) consists of units all of whose conjugates have absolute value \(1\). By Kronecker’s theorem, these are roots of unity. Since \(K_i\) is totally real, the only roots of unity are \(\pm1\). Therefore each logarithmic vector has at most two unit preimages.

Hence

\[ |U_iU_i| \le 2|\Lambda_i\cap Q_i(2S)|. \]

By Lemma 2.2 in the \((d_i-1)\)-dimensional space \(H_i\), with \(t=2\),

\[ |\Lambda_i\cap Q_i(2S)| \le 5^{d_i-1}|\Lambda_i\cap Q_i(S)| = 5^{d_i-1}|U_i|. \]

Therefore

\[ |U_iU_i| \le 2\cdot 5^{d_i-1}|U_i| \le 10^{d_i}|U_i|. \]

Let

\[ P:=\log 10. \]

Then

\[ \log|U_iU_i|\le a_i+P d_i. \]

4. Additive boxes of algebraic integers

For \(R\ge 1\), define

\[ C_i(R):= \left\{ x\in\mathcal O_{K_i}: |\sigma_{i,j}(x)|\le R \text{ for all }j=1,\dots,d_i \right\}. \]

The Minkowski lattice \(\sigma_i(\mathcal O_{K_i})\subset\mathbb R^{d_i}\) has covolume

\[ \sqrt{|\Delta_{K_i}|}\le D^{d_i/2}. \]

Lemma 4.1

For every \(R\ge 1\),

\[ |C_i(R)|\ge R^{d_i}D^{-d_i/2}, \]

and

\[ |C_i(R)|\le (5R)^{d_i}. \]

Proof

For the lower bound, apply Lemma 2.1 to the lattice \(\sigma_i(\mathcal O_{K_i})\) and the cube \([-R/2,R/2]^{d_i}\). Its difference body is \([-R,R]^{d_i}\), so

\[ |C_i(R)| \ge \frac{R^{d_i}}{\sqrt{|\Delta_{K_i}|}} \ge R^{d_i}D^{-d_i/2}. \]

For the upper bound, partition \([-R,R]^{d_i}\) into half-open cubes of side length \(1/2\). Since \(R\ge 1\), there are at most \((5R)^{d_i}\) such cubes.

Each small cube contains at most one point of \(\sigma_i(\mathcal O_{K_i})\). Indeed, if \(x\ne y\in\mathcal O_{K_i}\) had images in the same small cube, then \(z=x-y\ne0\) would satisfy

\[ |\sigma_{i,j}(z)|<\frac12 \]

for every \(j\). Therefore

\[ |N_{K_i/\mathbb Q}(z)| = \prod_{j=1}^{d_i}|\sigma_{i,j}(z)| < 1, \]

contradicting the fact that \(N_{K_i/\mathbb Q}(z)\) is a nonzero integer. Thus

\[ |C_i(R)|\le (5R)^{d_i}. \]

\(\square\)

Lemma 4.2

For every \(L\ge1\) and \(R\ge1\),

\[ |C_i(LR)| \le (2L+1)^{d_i}|C_i(R)|. \]

Proof

Apply Lemma 2.2 to the lattice \(\sigma_i(\mathcal O_{K_i})\subset\mathbb R^{d_i}\) and the cube \([-R,R]^{d_i}\). \(\square\)

5. Choosing the additive core

Every \(u\in U_i\) satisfies

\[ |\sigma_{i,j}(u)|\le e^S \]

for all \(j\).

Define constants

\[ \Theta:=\log(4e^S+1), \]
\[ M:=\Theta+\frac12\log D+1, \]

and

\[ \Gamma:=M+\log 5. \]

For each \(i\), set

\[ R_i:=\exp\left(\frac{a_i}{d_i}+M\right), \]

and define

\[ C_i:=C_i(R_i). \]

Let

\[ c_i:=\log |C_i|. \]

By Lemma 4.1,

\[ |C_i| \ge R_i^{d_i}D^{-d_i/2} = \exp\left(a_i+Md_i-\frac12(\log D)d_i\right) = \exp\left(a_i+(\Theta+1)d_i\right). \]

Thus

\[ c_i\ge a_i+(\Theta+1)d_i. \]

Also by Lemma 4.1,

\[ |C_i|\le (5R_i)^{d_i} = \exp\left(a_i+(M+\log5)d_i\right) = \exp(a_i+\Gamma d_i). \]

Thus

\[ c_i\le a_i+\Gamma d_i. \]

So for every \(i\) under consideration,

\[ a_i\ge\alpha d_i, \]
\[ a_i+(\Theta+1)d_i\le c_i\le a_i+\Gamma d_i. \]

6. Separating the \(U_i\)-dilates

We need a shift ensuring that the sets \(u(q+C_i)\) are disjoint.

Lemma 6.1

Let \(K\) be a characteristic-zero field, let \(U\subset K^\times\) and \(C\subset K\) be finite. Then all but finitely many integers \(q\) make the map

\[ U\times C\to K, \qquad (u,c)\mapsto u(q+c), \]

injective.

Proof

Suppose

\[ u(q+c)=v(q+c') \]

with \(u,v\in U\), \(c,c'\in C\). If \(u=v\), then \(c=c'\). If \(u\ne v\), then

\[ q(u-v)=vc'-uc, \]

so

\[ q=\frac{vc'-uc}{u-v}. \]

For each quadruple \((u,v,c,c')\) with \(u\ne v\), this excludes at most one value of \(q\). Since there are finitely many quadruples, only finitely many integers \(q\) are bad. \(\square\)

Choose such an integer \(q_i\) for \(U_i,C_i\), and define

\[ E_i:=U_i(q_i+C_i)\subset K_i. \]

By construction,

\[ |E_i|=|U_i||C_i|. \]

Finally, choose one embedding \(\sigma_{i,1}:K_i\hookrightarrow\mathbb R\), and set

\[ A_i:=\sigma_{i,1}(E_i)\subset\mathbb R. \]

Since \(\sigma_{i,1}\) is injective,

\[ |A_i|=|E_i|, \]
\[ |A_i+A_i|=|E_i+E_i|, \]

and

\[ |A_iA_i|=|E_iE_i|. \]

It remains to estimate the sumset and product set of \(E_i\).

7. Sumset estimate

Fix \(i\), and write

\[ d=d_i,\qquad a=a_i,\qquad c=c_i,\qquad N=|E_i|. \]

Then

\[ \log N=a+c. \]

Take two elements of \(E_i\):

\[ u(q_i+x),\qquad v(q_i+y), \]

with \(u,v\in U_i\) and \(x,y\in C_i\). Their sum is

\[ u(q_i+x)+v(q_i+y) = q_i(u+v)+ux+vy. \]

Therefore

\[ E_i+E_i \subseteq \bigcup_{u,v\in U_i} \bigl(q_i(u+v)+uC_i+vC_i\bigr). \]

Hence

\[ |E_i+E_i| \le |U_i|^2 \max_{u,v\in U_i}|uC_i+vC_i|. \]

Now if \(x,y\in C_i=C_i(R_i)\), then for every embedding \(\sigma_{i,j}\),

\[ |\sigma_{i,j}(ux+vy)| \le |\sigma_{i,j}(u)|\,|\sigma_{i,j}(x)| + |\sigma_{i,j}(v)|\,|\sigma_{i,j}(y)| \le 2e^S R_i. \]

Thus

\[ uC_i+vC_i\subseteq C_i(2e^S R_i). \]

By Lemma 4.2 with \(L=2e^S\),

\[ |C_i(2e^S R_i)| \le (4e^S+1)^d|C_i| = e^{\Theta d}|C_i|. \]

Therefore

\[ |E_i+E_i| \le |U_i|^2 e^{\Theta d}|C_i|. \]

Taking logarithms,

\[ \log|E_i+E_i| \le 2a+c+\Theta d. \]

Since \(\log N=a+c\),

\[ 2a+c+\Theta d = 2\log N-(c-\Theta d). \]

But

\[ c\ge a+(\Theta+1)d, \]

so

\[ c-\Theta d\ge a+d. \]

Therefore

\[ \log|E_i+E_i| \le 2\log N-(a+d). \]

We now compare \(a+d\) with \(\log N\). Since

\[ c\le a+\Gamma d, \]

we have

\[ \log N=a+c\le 2a+\Gamma d. \]

Write \(x=a/d\). We know \(x\ge\alpha\). Hence

\[ \frac{a+d}{\log N} \ge \frac{a+d}{2a+\Gamma d} = \frac{x+1}{2x+\Gamma}. \]

Because \(\Gamma>2\), the function

\[ x\mapsto \frac{x+1}{2x+\Gamma} \]

is increasing for \(x\ge0\). Thus

\[ \frac{a+d}{\log N} \ge \frac{\alpha+1}{2\alpha+\Gamma}. \]

Define

\[ \eta_+:=\frac{\alpha+1}{2\alpha+\Gamma}>0. \]

Then

\[ \log|E_i+E_i| \le (2-\eta_+)\log N, \]

so

\[ |E_i+E_i|\le N^{2-\eta_+}. \]

8. Product set estimate

We have

\[ E_iE_i \subseteq (U_iU_i)(q_i+C_i)(q_i+C_i). \]

Thus

\[ |E_iE_i| \le |U_iU_i|\, |(q_i+C_i)(q_i+C_i)|. \]

The trivial bound gives

\[ |(q_i+C_i)(q_i+C_i)|\le |C_i|^2. \]

Also,

\[ |U_iU_i|\le 10^d|U_i|. \]

Therefore

\[ |E_iE_i| \le 10^d|U_i||C_i|^2. \]

Taking logarithms,

\[ \log|E_iE_i| \le Pd+a+2c, \]

where \(P=\log10\). Since \(\log N=a+c\),

\[ Pd+a+2c = 2\log N-(a-Pd). \]

Because \(a\ge\alpha d\) and \(\alpha>P\),

\[ a-Pd>0. \]

Again using

\[ \log N\le 2a+\Gamma d, \]

we get

\[ \frac{a-Pd}{\log N} \ge \frac{a-Pd}{2a+\Gamma d}. \]

Writing \(x=a/d\ge\alpha\),

\[ \frac{a-Pd}{2a+\Gamma d} = \frac{x-P}{2x+\Gamma}. \]

The function

\[ x\mapsto \frac{x-P}{2x+\Gamma} \]

is increasing for \(x\ge P\), since its derivative is

\[ \frac{\Gamma+2P}{(2x+\Gamma)^2}>0. \]

Therefore

\[ \frac{a-Pd}{\log N} \ge \frac{\alpha-P}{2\alpha+\Gamma}. \]

Define

\[ \eta_\times:=\frac{\alpha-P}{2\alpha+\Gamma}>0. \]

Then

\[ \log|E_iE_i| \le (2-\eta_\times)\log N, \]

so

\[ |E_iE_i|\le N^{2-\eta_\times}. \]

9. Final choice of \(\delta\)

Set

\[ \delta := \frac12\min\{\eta_+,\eta_\times\}. \]

Since \(\eta_+>0\) and \(\eta_\times>0\), we have \(\delta>0\).

For every sufficiently large \(i\),

\[ |E_i+E_i|\le |E_i|^{2-\delta} \]

and

\[ |E_iE_i|\le |E_i|^{2-\delta}. \]

Passing through the embedding \(\sigma_{i,1}\), we obtain

\[ |A_i+A_i|\le |A_i|^{2-\delta} \]

and

\[ |A_iA_i|\le |A_i|^{2-\delta}. \]

Finally,

\[ \log|A_i| = \log|E_i| = a_i+c_i \ge 2a_i+(\Theta+1)d_i \ge (2\alpha+\Theta+1)d_i. \]

Since \(d_i\to\infty\), this implies

\[ |A_i|\to\infty. \]

Discarding finitely many initial terms and reindexing, we get an infinite sequence of finite sets \(A_i\subset\mathbb R\) such that \(|A_i|\to\infty\) and

\[ \max(|A_i+A_i|,\ |A_iA_i|) \le |A_i|^{2-\delta} \]

for every \(i\).

This proves the theorem. \(\square\)
