Below I first point out the genuine gap in the previous proof and then give a complete proof with that gap filled.

The earlier proof’s main unproved point was the lattice-counting assertion: one needs upper and lower estimates for lattice points of \(\sigma(\mathcal O_K)\) inside high-dimensional \(\ell^p\)-quasi-balls. The fix is to use the codifferent lattice and a standard transference bound to control the covering radius of \(\sigma(\mathcal O_K)\). This gives volume-counting estimates strong enough for the construction.

We use two standard external inputs:

  1. Martinet’s theorem: there are totally real number fields of arbitrarily large degree and bounded root discriminant.

  2. The Euclidean transference bound

    \[ \rho_2(\Lambda)\lambda_1(\Lambda^*)\le \frac d2 \]

    for a full-rank lattice \(\Lambda\subset \mathbb R^d\).

Everything else is proved below.

Proof

Let \(K/\mathbb Q\) be totally real of degree \(d\), with embeddings

\[ \sigma_1,\dots,\sigma_d:K\hookrightarrow \mathbb R. \]

Write

\[ \sigma(\alpha)=(\sigma_1(\alpha),\dots,\sigma_d(\alpha)). \]

For \(s>0\), define

\[ B_{s,d}(R) = \left\{ x\in\mathbb R^d:\sum_{j=1}^d |x_j|^s\le R^s \right\}. \]

Let

\[ V_{s,d}:=\operatorname{vol}(B_{s,d}(1)). \]

We use the formula

\[ V_{s,d} = \frac{\left(2\Gamma(1+1/s)\right)^d}{\Gamma(1+d/s)}. \tag{1} \]

This follows by evaluating

\[ \int_{\mathbb R^d} e^{-\sum |x_j|^s}\,dx \]

both as a product of one-dimensional integrals and by radial integration.

1. Volume saving under multiplication

For \(0<p\le 1\), define

\[ M_{p,d}:= \left(\frac{V_{p,d}^2}{V_{p/2,d}}\right)^{1/d}. \]

Using (1) and Stirling’s formula, for fixed \(p\),

\[ M_{p,d}\to m_p \]

as \(d\to\infty\), where

\[ m_p = 2^{1+2/p} \frac{\Gamma(1+1/p)^2}{\Gamma(1+2/p)}. \tag{2} \]

Moreover,

\[ m_p\sim 2\sqrt{\frac{\pi}{p}} \qquad(p\to0). \tag{3} \]

Hence \(m_p\to\infty\) as \(p\to0\).

2. Additive and multiplicative containment

For \(0<p\le1\),

\[ |u+v|^p\le |u|^p+|v|^p. \]

Thus

\[ B_{p,d}(R)+B_{p,d}(R) \subseteq B_{p,d}(2^{1/p}R). \tag{4} \]

Also, if \(x,y\in B_{p,d}(R)\), then by Cauchy–Schwarz,

\[ \sum_{j=1}^d |x_jy_j|^{p/2} \le \left(\sum |x_j|^p\right)^{1/2} \left(\sum |y_j|^p\right)^{1/2} \le R^p. \]

Since \((R^2)^{p/2}=R^p\), this gives

\[ B_{p,d}(R)\odot B_{p,d}(R) \subseteq B_{p/2,d}(R^2), \tag{5} \]

where \(\odot\) denotes coordinatewise multiplication.

3. Counting algebraic integers in \(B_{s,d}(R)\)

Let

\[ \Lambda_K:=\sigma(\mathcal O_K)\subset\mathbb R^d. \]

Then

\[ \det(\Lambda_K)=|D_K|^{1/2}=:\Delta_K. \]

Assume \(K\) has root discriminant bounded by \(B\), i.e.

\[ |D_K|^{1/d}\le B. \]

We prove the following counting estimate.

Lemma

For \(0<s\le1\), set

\[ \mu_s:=\frac B2 d^{1/s}. \]

Then for every \(R>\mu_s\),

\[ \frac{V_{s,d}R^d}{\Delta_K} \left(1-\left(\frac{\mu_s}{R}\right)^s\right)^{d/s} \le |\mathcal O_K\cap B_{s,d}(R)| \le \frac{V_{s,d}R^d}{\Delta_K} \left(1+\left(\frac{\mu_s}{R}\right)^s\right)^{d/s}. \tag{6} \]

Proof

The Euclidean dual lattice of \(\Lambda_K\) is

\[ \Lambda_K^*=\sigma(\mathfrak d_K^{-1}), \]

where \(\mathfrak d_K^{-1}\) is the codifferent.

If \(0\neq \beta\in\mathfrak d_K^{-1}\), then \(\beta\mathfrak d_K\subseteq \mathcal O_K\), so \((\beta)\mathfrak d_K\) is an integral ideal. Hence

\[ |N_{K/\mathbb Q}(\beta)|\,|D_K|\ge1. \]

Therefore

\[ |N_{K/\mathbb Q}(\beta)|\ge |D_K|^{-1}. \]

By AM–GM,

\[ \|\sigma(\beta)\|_2^2 = \sum_{j=1}^d |\sigma_j(\beta)|^2 \ge d\left(\prod_{j=1}^d|\sigma_j(\beta)|^2\right)^{1/d} = d\,|N_{K/\mathbb Q}(\beta)|^{2/d}. \]

Thus

\[ \|\sigma(\beta)\|_2 \ge \sqrt d\,|D_K|^{-1/d} \ge \frac{\sqrt d}{B}. \]

So

\[ \lambda_1(\Lambda_K^*)\ge \frac{\sqrt d}{B}. \]

By the transference inequality,

\[ \rho_2(\Lambda_K)\lambda_1(\Lambda_K^*)\le \frac d2, \]

hence

\[ \rho_2(\Lambda_K)\le \frac B2\sqrt d. \]

For \(0<s\le1\),

\[ \|x\|_s \le d^{1/s-1/2}\|x\|_2. \]

Therefore the \(s\)-quasi-norm covering radius is at most

\[ \mu_s=\frac B2 d^{1/s}. \]

Choose a measurable fundamental domain \(F\) for \(\Lambda_K\) contained in \(B_{s,d}(\mu_s)\).

For the upper bound, if \(\lambda\in \Lambda_K\cap B_{s,d}(R)\) and \(f\in F\), then

\[ \lambda+f\in B_{s,d}\bigl((R^s+\mu_s^s)^{1/s}\bigr). \]

Thus

\[ |\Lambda_K\cap B_{s,d}(R)|\Delta_K \le V_{s,d}R^d \left(1+\left(\frac{\mu_s}{R}\right)^s\right)^{d/s}. \]

For the lower bound, let

\[ R_-=(R^s-\mu_s^s)^{1/s}. \]

Every point of \(B_{s,d}(R_-)\) lies in some translate \(\lambda+F\). If \(z=\lambda+f\) with \(z\in B_{s,d}(R_-)\) and \(f\in F\), then

\[ \|\lambda\|_s^s = \|z-f\|_s^s \le \|z\|_s^s+\|f\|_s^s \le R_-^s+\mu_s^s = R^s. \]

Hence \(\lambda\in\Lambda_K\cap B_{s,d}(R)\), so

\[ V_{s,d}R_-^d \le |\Lambda_K\cap B_{s,d}(R)|\Delta_K. \]

This is the lower bound in (6). \(\square\)

4. Choosing the number fields

By Martinet’s theorem, there exists an infinite sequence of totally real fields \(K_i\) with degrees

\[ d_i=[K_i:\mathbb Q]\to\infty \]

and uniformly bounded root discriminant

\[ |D_{K_i}|^{1/d_i}\le B. \]

Set

\[ \Delta_i:=|D_{K_i}|^{1/2}. \]

Then

\[ \Delta_i^{1/d_i}\le B^{1/2}. \tag{7} \]

Choose \(0<p\le1\) so small that

\[ m_p>B^{1/2}. \]

Choose \(\theta>0\) such that

\[ e^\theta B^{1/2}<m_p. \]

Since \(M_{p,d}\to m_p\), after discarding finitely many \(i\), we have

\[ \frac{M_{p,d_i}}{\Delta_i^{1/d_i}}\ge e^\theta. \tag{8} \]

Let

\[ q:=p/2, \qquad L:=\frac{\log 2}{p}. \]

5. Choosing the radii

For a large constant \(C>L\), define \(R_i\) by

\[ \frac{V_{p,d_i}R_i^{d_i}}{\Delta_i} = e^{Cd_i}. \tag{9} \]

Equivalently,

\[ R_i=e^C\Delta_i^{1/d_i}V_{p,d_i}^{-1/d_i}. \]

For fixed \(p\), Stirling’s formula implies

\[ \sup_d d^{1/p}V_{p,d}^{1/d}<\infty. \]

Therefore, for some constant \(H_p\),

\[ d^{1/p}V_{p,d}^{1/d}\le H_p \qquad\text{for all }d. \tag{10} \]

From (9) and \(\Delta_i^{1/d_i}\ge1\),

\[ \left(\frac{\mu_p}{R_i}\right)^p \le \left(\frac B2 H_p e^{-C}\right)^p =:\alpha(C), \]

and

\[ \left(\frac{\mu_q}{R_i^2}\right)^q \le \left(\frac B2 H_p^2 e^{-2C}\right)^q =:\beta(C). \]

Both \(\alpha(C)\) and \(\beta(C)\) tend to \(0\) as \(C\to\infty\). Choose \(C\) so large that \(\alpha(C),\beta(C)<1/2\), and with

\[ \eta(C):=\max\left(\frac{2\alpha(C)}p,\frac{\beta(C)}q\right), \]

we have

\[ \eta(C)<\frac{C-L}{4} \qquad\text{and}\qquad \eta(C)<\frac{\theta}{4}. \tag{11} \]

For this fixed \(C\), the counting lemma gives

\[ e^{(C-\eta)d_i} \le |\mathcal O_{K_i}\cap B_{p,d_i}(R_i)| \le e^{(C+\eta)d_i}, \tag{12} \]

where \(\eta=\eta(C)\).

6. Defining the sets \(A_i\)

Let

\[ P_i:=\mathcal O_{K_i}\cap B_{p,d_i}(R_i). \]

Choose one real embedding \(\sigma_{i,1}:K_i\hookrightarrow\mathbb R\), and define

\[ A_i:=\sigma_{i,1}(P_i)\subset\mathbb R. \]

Since \(\sigma_{i,1}\) is injective,

\[ |A_i|=|P_i|. \]

Write

\[ n_i:=|A_i|. \]

By (12),

\[ n_i\ge e^{(C-\eta)d_i}. \tag{13} \]

In particular \(n_i\to\infty\).

7. Sumset estimate

By (4),

\[ P_i+P_i \subseteq \mathcal O_{K_i}\cap B_{p,d_i}(2^{1/p}R_i). \]

Hence

\[ |A_i+A_i| = |P_i+P_i| \le |\mathcal O_{K_i}\cap B_{p,d_i}(2^{1/p}R_i)|. \]

Using the upper bound from the counting lemma and (9),

\[ |A_i+A_i| \le e^{\eta d_i} \frac{V_{p,d_i}(2^{1/p}R_i)^{d_i}}{\Delta_i} = e^{\eta d_i}2^{d_i/p}e^{Cd_i}. \]

Thus

\[ |A_i+A_i| \le e^{(C+L+\eta)d_i}. \tag{14} \]

Using (13),

\[ d_i\le \frac{\log n_i}{C-\eta}. \]

Therefore

\[ |A_i+A_i| \le n_i^{(C+L+\eta)/(C-\eta)}. \]

Now

\[ 2-\frac{C+L+\eta}{C-\eta} = \frac{C-L-3\eta}{C-\eta}>0 \]

by (11). Define

\[ \delta_+ := \frac{C-L-3\eta}{C-\eta}. \tag{15} \]

Then

\[ |A_i+A_i|\le n_i^{2-\delta_+}. \tag{16} \]

8. Product-set estimate

By (5),

\[ P_iP_i \subseteq \mathcal O_{K_i}\cap B_{q,d_i}(R_i^2), \qquad q=p/2. \]

Thus

\[ |A_iA_i| = |P_iP_i| \le |\mathcal O_{K_i}\cap B_{q,d_i}(R_i^2)|. \]

Using the counting lemma,

\[ |A_iA_i| \le e^{\eta d_i} \frac{V_{q,d_i}R_i^{2d_i}}{\Delta_i}. \tag{17} \]

From (9),

\[ R_i^{d_i} = \frac{e^{Cd_i}\Delta_i}{V_{p,d_i}}. \]

Therefore

\[ \frac{V_{q,d_i}R_i^{2d_i}}{\Delta_i} = e^{2Cd_i} \Delta_i \frac{V_{q,d_i}}{V_{p,d_i}^2}. \]

Since

\[ M_{p,d_i}^{d_i} = \frac{V_{p,d_i}^2}{V_{q,d_i}}, \]

we get

\[ \frac{V_{q,d_i}R_i^{2d_i}}{\Delta_i} = e^{2Cd_i} \left(\frac{\Delta_i^{1/d_i}}{M_{p,d_i}}\right)^{d_i}. \]

By (8),

\[ \left(\frac{\Delta_i^{1/d_i}}{M_{p,d_i}}\right)^{d_i} \le e^{-\theta d_i}. \]

So (17) yields

\[ |A_iA_i| \le e^{(2C-\theta+\eta)d_i}. \tag{18} \]

Again using (13),

\[ |A_iA_i| \le n_i^{(2C-\theta+\eta)/(C-\eta)}. \]

Now

\[ 2-\frac{2C-\theta+\eta}{C-\eta} = \frac{\theta-3\eta}{C-\eta}>0 \]

by (11). Define

\[ \delta_\times := \frac{\theta-3\eta}{C-\eta}. \tag{19} \]

Then

\[ |A_iA_i| \le n_i^{2-\delta_\times}. \tag{20} \]

9. Final choice of \(\delta\)

Set

\[ \delta:=\frac12\min(\delta_+,\delta_\times)>0. \]

Then for all sufficiently large \(i\),

\[ |A_i+A_i|\le |A_i|^{2-\delta} \]

and

\[ |A_iA_i|\le |A_i|^{2-\delta}. \]

Thus

\[ \max(|A_i+A_i|,|A_iA_i|) \le |A_i|^{2-\delta}. \]

Since \(|A_i|\to\infty\), after discarding finitely many initial terms and relabeling, we obtain the required infinite sequence.

\(\square\)
